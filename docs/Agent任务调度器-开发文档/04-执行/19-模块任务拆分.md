# 模块任务拆分

**粒度**：一个任务 = 一个人 0.5–2 天。标题是「动词 + 具体对象 + 可验证产出」。
**每条验收标准都必须可客观判定**，且引用它覆盖的边界编号（`E-XX`，见 13 节）。

**所有任务的验收标准都隐含一条**：`pnpm -w check` 必须通过
（`biome ci .` + `tsc -b --noEmit` + `vitest run`）——这是每个任务的本地强制点；
三平台发布还必须通过 17 节的 CI 矩阵。
下表中只在需要强调时才重复写出。
