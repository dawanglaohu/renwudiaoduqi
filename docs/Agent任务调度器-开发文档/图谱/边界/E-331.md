# E-331　查 bug 的手动触发与失败重跑

| | |
|---|---|
| 触发条件 | 开关为关时人想对某任务查一次；或查 bug 运行失败后人想再查 |
| 期望行为 | 产品不提供手动查 bug 端点、界面不渲染置灰入口，人复制交接台该任务的查 bug 提示词自己派或按 E-59 打回／放行；`E_PIPELINE_STAGE_DISABLED` 不再有「手动派查 bug」分支；查 bug 运行失败（E-323）后允许对该 `kind='bughunt'` 行调既有 `POST /runs/:id/rerun`（复用派发载荷、同一工作树），仅当任务仍停在 `bughunt_failed` 的 `awaiting_human`，派出即作废 E-323 开的闸门、不读开关当前值；返工后再审 pass 逐次读开关，可能再派一次查 bug，不设「每任务一次」上限 |
| 归属模块 | [[M7]] |
