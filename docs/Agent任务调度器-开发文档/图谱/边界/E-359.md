# E-359　零产出退出审批卡的三态 stderr 与「换 agent 重派」落点

| | |
|---|---|
| 触发条件 | 审批卡 `comment==='exited_before_output'`；`run.exited` 有／无 `stderrTail` 键或事件缺失；用户点「换 agent 重派」；手机档 |
| 期望行为 | `GateDto.context.stderrTail` 是可判别联合：`{kind:'lines', lines}`（空数组显示「无 stderr 输出」，行内 `[REDACTED]` 显示「[已脱敏]」）／`{kind:'unavailable', reason:'legacy_run'}`（找到 `run.exited` 但无该键或形状损坏，显示「无记录（旧运行）」并 warn）／`{kind:'unavailable', reason:'event_missing'}`（找不到 `run.exited` 或 ndjson 不可读，显示「事件缺失」），由 service 判定、前端穷举 switch；同一运行多条 `run.exited` 取最后一条；其他种类审批卡 `context` 不含该键；「换 agent 重派」→ `selection-store.openReassign(taskId)`：先展开所在批次、左栏有筛选则清除并轻提示「已清除筛选以定位 〈ID〉」、滚到该行高亮、焦点落到 agent 选择器、预选当前快照的 agent，用户改后走常规 `POST /runs`，不换 agent 直接派也允许；到达时状态已变则按当前状态与既有 `implLocked` 规则；重复点击幂等；审批卡不因跳转消失；手机档不渲染该按钮（不是置灰），`lines` 折叠显示末 5 行可展开到 20 行（决策 126、131） |
