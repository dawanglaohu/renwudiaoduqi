# E-339　刷新期间与并发刷新

| | |
|---|---|
| 触发条件 | 用户点「刷新清单」后 `live` 与登录探测在途；同一 agent 被连点或 `availability_changed` 与手动刷新 5 秒内重叠 |
| 期望行为 | 在途期间非 refresh 的 `GET /agents/:id/models` **不等待**，用旧 `live`（有缓存）或空 `live`（无缓存）+ config + builtin + history 立即返回并 `isRefreshing:true`；同一 agent 同时只一个 `live` 子进程、一个登录探测（`inflight` Map 去重，后续调用复用同一 promise）；刷新按钮在途时 disabled；`live` 失败不抛错、HTTP 200、`liveFailure` 字段说明原因 |
