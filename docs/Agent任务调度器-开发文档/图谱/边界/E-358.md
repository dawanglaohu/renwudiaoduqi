# E-358　设置页的分层值、覆盖与清除

| | |
|---|---|
| 触发条件 | 打开设置页 agent 卡片；用户设覆盖、显式「覆盖为跟随」或点「恢复默认」；配置文件缺字段或解析失败；dsh |
| 期望行为 | `AgentEntryDto.layers` 三层 `{builtin, config, override, hasOverride}`（模型与思考强度各一份），`effective` 由 service 按「覆盖 ?? 配置 ?? 内置」算出，前端不从清单 config 组反推；`config` 为 null 时三行该格「—」不弹错误；`hasOverride:false` 时生效 = 配置 ?? 内置，`hasOverride:true, override:null` 时生效 null（不传参，即使配置文件有值）；配置文件里的厂商原值以 `{vendor}` 原样携带；每个字段各自一个「恢复默认」，无覆盖时置灰不隐藏、title「当前没有覆盖」；「恢复默认」发 `PATCH /agents/:id {clearOverrides:['defaultModel']}`，只清该字段；`defaultEffortTier: null` 不在 `clearOverrides` 里 → 写入「覆盖为跟随」；body 同时含 `clearOverrides:['x']` 与 `x` → `E_VALIDATION`，重复或未知字段名 → `E_VALIDATION`，空数组视为未提供；PATCH 失败「你的覆盖」保持原值不乐观清空、按 E-36 原样展示；对 dsh 传 `clearOverrides:['defaultEffortTier']` 幂等成功，dsh 的思考强度块显示「该 agent 不支持」不渲染三行与按钮；用户点「刷新」后 `config` 与 `effective` 随缓存更新、`override` 不动；已派快照不受清除影响；`<400px` 三行竖排、按钮排在三行之下（决策 125、128、132） |
