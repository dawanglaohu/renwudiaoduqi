# E-343　指派快照与配置当前值后来不一致

| | |
|---|---|
| 触发条件 | 任务派出后用户手改了 `config.toml`／`settings.json` 的模型或思考强度，或改了注册表默认 |
| 期望行为 | **不回写快照、不改在途运行**：`assignment_json` 只写不改（E-93 同法），该任务后续阶段仍读派发时那一份；设置页「当前配置」随文件 mtime 刷新显示新值；参照条不高亮不一致（它只对自报值高亮，E-37／E-256）；只有换 agent 重派或用户显式清除覆盖才产生新快照（E-33、E-34） |
| 归属模块 | [[M8]] |
