# E-309　窗口数调小

| | |
|---|---|
| 触发条件 | 用户把并行窗口数从 N 调到 M＜N，而在跑的流水线数 ＞M |
| 期望行为 | 不杀任何在跑流水线，只停止补位；`lanes` 仍按实际占用返回并标 `overLimit`，空出的泳道不再补，直到占用 ≤M；调整立即生效、不需重启批次；被移除的空泳道其历史行随之消失、不迁移 |
| 归属模块 | [[M8]] |

- [[M9-T21]]　任务流水线泳道与历史行
