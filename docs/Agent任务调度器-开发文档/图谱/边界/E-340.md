# E-340　history 来源的取值

| | |
|---|---|
| 触发条件 | 打开指派面板或设置页时派生「该 agent 历史用过的模型」 |
| 期望行为 | 只从 `runs` 派生一条 SQL：`state` 为成功终态 `landed`、`model_name` 非空、按 `agent_id` 全局（不分文档、不分 kind）、DISTINCT、按最近一次 `ended_at` 倒序、最多 20 条；`awaiting_human`（不论 reason）、`failed`、`aborted` 与人工从 `awaiting_human` 直接标 landed 且无成功运行的都不计；pi 的模型串剥掉 `:〈thinking〉` 后缀、保留 `provider/model` 前缀（只在 `adapters/pi` 做）；与 `live`／`config` 同名的归靠前来源、history 组去重；历史模型已下线仍列出不标「已下线」；每次现查不缓存，同一库重启后顺序逐字节相同 |
| 归属模块 | [[M4]] |
