# E-332　阶段顺序与未知阶段

| | |
|---|---|
| 触发条件 | 前端要画未来阶段的虚线行；或 daemon 下发的 `stage` 不在已知集合内 |
| 期望行为 | 阶段链顺序来自 shared 的 `PIPELINE_STAGES = ['implement','review','bughunt','landing']`（`lib/` 只 `import type`，值由容器作 `stageOrder` 传入）；`stage='rework'`／`queued` 落在实施行（标签「返工实施 · 第 N 轮」／「排队」），不是独立行；未来行 = 顺序表里当前阶段之后的项去掉 `bughunt`（只在该任务出现 `kind='bughunt'` 运行后插入，开关开着也不预画）；`landing` 恒最后一行；`stage` 不在 `LANE_STAGES` 内 → 当前行标签显示「—」、未来行不画、不抛错；daemon 侧 arch 测试断言 `deriveLanes()` 可能产出的阶段集合与 shared `LANE_STAGES` 逐项相等，加阶段必须同 PR 改两处 |
| 归属模块 | [[M9]] |
