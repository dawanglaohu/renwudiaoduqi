# E-357　参照条「来源」段的取值与缺失

| | |
|---|---|
| 触发条件 | 参照条渲染每条运行的第三段；`assignmentSource` 为 `agent_default`、四值之外或缺失；被跟随任务未记录或已从文档删除；「N 分钟前探测」的时间推进 |
| 期望行为 | `RunDto.assignmentSource`（`runs.assignment_source`，NULL 读作 `task`）与 `followedTaskId`（service 从快照 `assignment_json` 联结取，不新增 `runs` 列）是唯一来源，前端不读快照不算取值链；`task` → 「来源：任务指派」、`review_override` → 「来源：审查覆盖」、`wrapup_settings` → 「来源：收口设置（跟随 〈taskKey〉）」，`followedTaskId` 为 null 时「（跟随任务未记录）」；`agent_default` → 「来源：任务指派（agent 默认）」括注可见、title 说明按 agent 当前生效默认运行，模型／强度为空时仍显示「—」；四值之外或缺失 → 「来源：—」并把原始值放 title，不报错不映射；后端只在模型与强度**都**回落时返回 `agent_default`，只回落一项返回 `task`，前端不自行对比推断半回落；被跟随任务 ID 不在当前文档 → 显示 ID 文本不做链接；`compact`／`narrow` 档用短文案「任务／审查／收口」并把长文案放 title，括注不省略允许换行；第四段可截断、前三段不截断；「N 分钟前探测」由 `hooks/use-minute-tick.ts` 的模块级 60 秒 tick 驱动（只碰本地时钟、无订阅者不起、不 import api），时钟回拨显示「刚刚」，超 24 小时灰显（决策 124、127、129） |
