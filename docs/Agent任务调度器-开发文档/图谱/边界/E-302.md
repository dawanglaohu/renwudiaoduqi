# E-302　任务终态时会话进程还在

| | |
|---|---|
| 触发条件 | 任务进入 landed／failed／aborted／interrupted，而该任务的实施／审查／查 bug 会话进程仍存活 |
| 期望行为 | 结束并归档该任务全部会话：进程走 `platform.killTree` 两阶段（E-119），每条运行写 `session_archived_at`，`vendor_session_ref` 从此只作只读引用；同一泳道的下一个任务一律新建会话，**绝不把已归档会话拿来跑新任务** |
| 归属模块 | [[M6]] |
