# E-103　磁盘占用达告警阈值

| | |
|---|---|
| 触发条件 | 捕获的日志累积过多 |
| 期望行为 | 顶部横幅列出占用最大的几个任务，提供「按任务 / 按时间归档」的手动入口；默认不自动删除 |
| 归属模块 | [[M1]] |

## 被这些任务兜底

- [[M1-T5]]　磁盘占用统计、写满兜底与受限删除原语

## 验证记录

<!-- notes:begin -->
- `packages/daemon/test/unit/disk-watch.test.ts`「E-103」组：run 目录总字节达到阈值时一次巡检即发布 `system.disk_warning`（scope `system`，payload 带 `path` 与英文 message）并把派发标志置为 `disk_threshold`；低于阈值不发事件、不置标志。
- `packages/daemon/test/unit/disk-primitives.test.ts`「E-103: calculateDiskUsage」：按 run 汇总并降序排列、阈值判定、剩余空间低于下限也算超限、根目录尚不存在按空处理。
- `packages/daemon/test/integration/disk-full-and-system-routes.test.ts`：`GET /api/v1/system/usage` 只返回 `{dataDirBytes, byRun[], warnThreshold}` 且 `byRun` 降序。Windows 本地 `pnpm -w check` 通过。
