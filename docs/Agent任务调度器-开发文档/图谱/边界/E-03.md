# E-03　端口被占用或多实例

| | |
|---|---|
| 触发条件 | daemon 端口被占用，或同机多用户登录 |
| 期望行为 | 端口可配置 + 单实例锁；锁范围为「整机一个 daemon」（Windows 锁文件位于 `C:\ProgramData\agent-scheduler\daemon.lock`，每用户目录不构成单例边界；`AGSCHED_PORT` 不同的第二个实例同样被拒）。第二个实例启动时读锁文件中的持有者 pid 并探测存活：存活（同一锁 / 同一端口仍在听）→打印已有实例 pid 与端口后以非 0 退出，「把请求让给已有实例」即拒绝自身启动并提示客户端直连该 pid 对应端口，不做进程间透传；持有者已死→删陈旧锁重新竞争。端口被非本 daemon 进程占用时 listen 失败、释放锁并以非 0 退出，不在另端口上起服务。锁覆盖 daemon 全生命周期，持有者只有进程退出才释放；绝不允许两个调度器同时推进同一批次 |
| 归属模块 | [[M1]] |
