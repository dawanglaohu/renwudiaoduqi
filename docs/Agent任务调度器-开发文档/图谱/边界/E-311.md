# E-311　一个任务的多个阶段同时在跑

| | |
|---|---|
| 触发条件 | 同一任务的实施运行已退出、审查运行在跑，或查 bug 运行在跑 |
| 期望行为 | 全部阶段共用**同一个槽位**：槽位按任务计数，不按运行计数；审查与查 bug 运行不额外占窗口，但各占该 agent 并发上限 1 名额（M8-T1 的计数不变）；`lanes[].currentRunId` 指向当前阶段的运行 |
| 归属模块 | [[M8]] |
