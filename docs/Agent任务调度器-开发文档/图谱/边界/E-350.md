# E-350　清单同名去重、别名与「当前配置」的位次

| | |
|---|---|
| 触发条件 | 同一模型名同时出现在多个来源；claude 的 `config` 当前值本身是别名（本机 `opus[1m]`）；注册表 `builtinModels` 为空或条目非法 |
| 期望行为 | 按 `live → config → builtin → history` 顺序追加，`name` 精确比较（不 trim、不大小写归一、不做别名归并，E-45），同名只保留更靠前者，daemon 去重后前端不再去重；`config` 当前值是别名时只出现一次、归 config 组并默认选中，builtin 组不重复；`builtinModels` 缺失或空数组 → builtin 组不渲染；条目 `name` 含空白或控制字符 → 注册表加载时拒绝**该条 agent**并 warn，其余 agent 照列；非 claude 的 agent 填了 `builtinModels` 同样列出（通用字段，不特判）；将来 claude 有了列模型命令，`live` 同名胜出、builtin 组自动缩小；claude 永远 `isComplete:false` → 下拉底部固定一行「清单可能不全，可手填」，「刷新清单」对它只重读配置与历史；选了别名后运行失败按 E-36 原样展示、不从清单移除 |
| 归属模块 | [[M4]] |
