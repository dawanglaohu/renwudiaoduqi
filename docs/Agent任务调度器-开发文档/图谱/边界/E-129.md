# E-129　路径含空格、Unicode、元字符或 Windows 长路径

| | |
|---|---|
| 触发条件 | 工作区、数据目录或 agent 路径包含这些字符，或是 UNC / 超过传统 260 字符限制 |
| 期望行为 | 按当前平台规范化并以独立 argv 传递；Windows 在进入文件系统前使用长路径命名空间，不得以传统 260 字符阈值拒绝。若超过接口或当前文件系统上限，必须在启动/写入前报告实际限制 |
| 归属模块 | [[M1]] |
