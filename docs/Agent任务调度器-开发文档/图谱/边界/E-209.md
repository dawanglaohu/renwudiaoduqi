# E-209　升级后自启项指向旧路径

| | |
|---|---|
| 触发条件 | 安装位置、macOS `.app` 位置或 Node 脚本参数变化，原生自启项仍引用旧启动方式 |
| 期望行为 | 壳每次启动根据实际安装位置解析完整 `DaemonLaunchSpec`；`register` 幂等接收该冻结对象，逐字段校验原生注册项与当前绝对 `file`、`args[]`、绝对 `cwd`，不一致则重写；桌面按钮和自启共用同一对象且恒不经 shell，安装包不得预写固定绝对路径；重写失败降级为「需手动启动」并给出该平台可复制命令 |
