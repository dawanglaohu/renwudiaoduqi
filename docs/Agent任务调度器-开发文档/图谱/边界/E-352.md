# E-352　跨家审查覆盖的快照与不可用

| | |
|---|---|
| 触发条件 | `reviewOverride.agentId` 与实施快照 `launch_spec_json` 的 agent 不同家；或派审查时覆盖 agent 已不在注册表／不可用 |
| 期望行为 | 派审查时同一事务 INSERT 子快照（`parent_snapshot_id` 指向实施快照，文本列、`contract_hash`、`task_paths_json`、`bug_prompt`、`assignment_json` 逐字复制，`launch_spec_json` 换成覆盖 agent 当时的注册表副本），审查行 `snapshot_id` 指向子快照；同家覆盖或无覆盖不建子快照、直接挂实施快照；「最近快照」类查询（收口跟随、指派面板「上次派发」、契约比对）一律 `parent_snapshot_id IS NULL`，子快照不参与「契约是否变化」判断；覆盖 agent 不可用 → 不建、不派、不换家，实施行 `awaiting_human` 并在闸门 comment 写 `review_agent_unavailable`；审查运行 rerun 与第 N+1 轮续接复用同一子快照；`reviewOverride` 中途改了只影响新开的审查会话，续接同会话时 `resolveAssignment` 结果与第 N 轮不等则走 `new_session`（E-304）；子快照在快照详情里标「审查覆盖快照 · 父快照 〈id〉」，不在任务快照列表主行出现 |
