# E-139　Node 版本过低

| | |
|---|---|
| 触发条件 | daemon 启动时 `node --version` 低于声明的最低大版本 |
| 期望行为 | 自检失败并打印所需版本后退出，不静默降级或半残运行。**版本检查必须由旧版 Node 可解析的纯 JS 垫片（`.mjs`，不含 TypeScript 语法、不依赖 Node 22 专属选项）在加载 TypeScript 与任何 Node 22 专属参数之前执行**；垫片只做版本判定，失败时打印 `requires Node.js >= 22` 并以非 0 退出，通过后才加载 `main.ts` 入口（Node 22 也不允许直接跑 `.ts`，因此垫片是正式启动入口） |
| 归属模块 | [[M1]] |
