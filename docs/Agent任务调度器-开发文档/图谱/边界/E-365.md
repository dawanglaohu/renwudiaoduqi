# E-365　后续批次无逐任务指派或默认 Agent 不可用

| | |
|---|---|
| 触发条件 | 只配置一次文档默认指派；后续任务存在局部覆盖；指定 Agent 离线 |
| 期望行为 | 任务草稿优先，其次文档默认，再读 Agent 配置；默认与草稿共用 effort: EffortValue，合法 vendor 原值经既有取值域校验并冻结，不丢成三档；无局部覆盖的后续批次直接沿用，指定 Agent 不可用不静默换家 |
