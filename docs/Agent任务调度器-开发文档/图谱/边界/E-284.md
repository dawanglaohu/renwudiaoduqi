# E-284　自动展开只增不减

| | |
|---|---|
| 触发条件 | `batch.advanced` 到达时该批已被用户手动折叠，或本会话已展开多批 |
| 期望行为 | 事件到达且 `to ∈ {running, wrapping, awaiting_landing, needs_attention}` 时并入展开集，永不从集合删元素（除切换文档整体清空与用户手动 toggle）；不折叠用户手动展开的批；展开集只存内存，刷新后回到 daemon 的 `defaultExpanded` |
| 归属模块 | [[M9]] |
