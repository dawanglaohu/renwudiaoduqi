# E-345　codex app-server 不可用、握手失败或超时

| | |
|---|---|
| 触发条件 | `codex app-server` 起不来、`initialize`／`model/list` 返回 `error`、协议字段变化，或 10 秒（codex 出厂 `modelsLive.timeoutMs`）内无响应 |
| 期望行为 | `live` 缺失：`isComplete:false`、`liveFailure.reason` 为 `rpc_error`／`unparsable`／`timeout`／`spawn_failed`，清单回落 `config + builtin + history`，HTTP 200 不报错；设置页提示「实时清单获取失败（〈原因〉，N 秒），可刷新重试」，超时值来自注册表则提示里带该值；stderr 上 `codex_models_manager` 的远端刷新 ERROR 只进日志不影响 `ok`；协议里无 id 的通知（如 `remoteControl/status/changed`）与非本请求 id 的响应一律忽略；收齐后 `kill()` 不等它自然退出；派发不受影响 |
| 归属模块 | [[M4]] |
