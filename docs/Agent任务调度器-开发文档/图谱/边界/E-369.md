# E-369　执行中文档变更、不可读或契约待复核

| | |
|---|---|
| 触发条件 | 任务 ID/contractHash 变化、源失效，或仅 readiness/reasons 更新 |
| 期望行为 | 契约指纹变化或不可读暂停新自动派发，在途快照不变；已完成批次新增任务、移批、删任务或成员契约变化时，membershipFingerprint 与 completionFingerprint 不一致即作废旧完成证据；显式开始/继续经 membership_invalidated 受控白名单把受影响 done 或真实成员变化的活动状态重置 idle；旧来源 starting/running 在途时以 source_runs_pending 等待，旧代 queued 收口按既有 queued→failed 对账，旧代回调只入历史；确认成员变化才建立新 generationId，每代保留2轮有效自动收口/6次物理尝试上限，同源控制不清额度；新成员重新验收收口，保留已验收任务与历史；仅就绪元数据变化不暂停整份文档，就绪兄弟继续 |
| 归属模块 | M8、M9 |
