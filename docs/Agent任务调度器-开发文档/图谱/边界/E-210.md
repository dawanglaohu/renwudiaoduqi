# E-210　注册被系统拒绝

| | |
|---|---|
| 触发条件 | Task Scheduler、`launchctl` 或 `systemctl --user` 因权限或策略拒绝 |
| 期望行为 | 注册失败**必须非致命**：daemon 仍由壳当场拉起、功能完整，仅重启后需手动开壳；设置页提供「重试注册自启」按钮并显示原生错误 |
| 归属模块 | [[M10]] |

## 被这些任务兜底

- [[M10-T2]]　三平台桌面壳（Tauri v2）
