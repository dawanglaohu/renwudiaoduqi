# E-341　阶段覆盖字段为空、或在非审查阶段出现

| | |
|---|---|
| 触发条件 | `reviewOverride` 只填 `agentId`；或 `rework`／`bughunt`／`wrapup-fix` 阶段派发时设置里有 `reviewOverride` |
| 期望行为 | `resolveAssignment()` 是唯一取值链：`review` 阶段 `modelName`／`effortTier` 为空回落任务指派（同家沿用，跨家见 E-342）；**`rework`、`bughunt`、`wrapup-fix` 三个阶段逐字读任务指派快照，零回落**，传入的 `stageOverride`／`manualOverride` 被忽略（单测断言输出 `===` 输入）；在途运行禁止读注册表当前 `defaultModel`／`defaultEffortTier`（E-93），只有 `implement` 首派与跨家覆盖时由 service 现读 agent 默认；`source` 四值 `task`／`review_override`／`wrapup_settings`／`agent_default` 写进 `runs.assignment_source` 并随 `RunDto` 下发 |
| 归属模块 | [[M8]] |
