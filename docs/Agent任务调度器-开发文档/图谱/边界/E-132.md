# E-132　平台分支散落各处

| | |
|---|---|
| 触发条件 | 业务代码直接判断 `process.platform`，或某一宿主静默走另一宿主逻辑 |
| 期望行为 | 一律收口到单一 `platform` 契约及 Windows/macOS/Linux 三个适配器（进程树终止、自启、配置目录、路径与可执行文件解析）；三平台之外返回 `E_PLATFORM_UNSUPPORTED` |
| 归属模块 | [[M1]] |
