# E-360　导入或切换文档意外启动

| | |
|---|---|
| 触发条件 | 新导入、刷新、重绑定或页面切换 |
| 期望行为 | 新导入保持 idle；这些操作不新增执行授权或直接建运行；已有 running 计划在来源不变时继续，来源变化则按 E-369 暂停；仅文档级开始授予执行权 |
| 归属模块 | M8、M9 |
