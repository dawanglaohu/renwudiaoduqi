# E-325　历史行的数量与替换

| | |
|---|---|
| 触发条件 | 泳道先后跑过多个任务 |
| 期望行为 | 只保留最近一条：新任务补位时替换为刚结束的任务，被挤出的任务去批次树／任务列表／运行详情看（E-27）；泳道第一个任务不渲染历史行、不放占位、不出分隔线；历史行绑定在本泳道跑过的那组已归档运行（按 run id）而不绑任务，同一任务重派到别的泳道时本泳道历史行仍显示归档流水线自己的终态、不出现两处呼吸；折叠一行的内容固定为 `taskKey · 标题截断 · 终态徽标（字形+文字）· 第 N 轮（N≥2 才显示）· 总耗时 · 「会话已归档」chip`；收口运行占过的泳道历史行显示「批次收口 · 第 N 轮 · 第 M 批」+ 收口裁定徽标；daemon 重启／页面刷新后历史行来自快照，不由前端内存推算 |
