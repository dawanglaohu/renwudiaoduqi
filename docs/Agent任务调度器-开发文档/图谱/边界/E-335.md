# E-335　登录态探测超时、命令不存在或输出无法解析

| | |
|---|---|
| 触发条件 | 探测子进程 5 秒（注册表可覆盖）内未退出；`resolvedPath` 为空；stdout 不匹配任何解析规则 |
| 期望行为 | 置 `unknown` 并给 reason（`timeout`／`exec_missing`／`spawn_failed`／`unparsable`／`exit_nonzero`），`warningCode` 为 `E_AGENT_LOGIN_PROBE_FAILED` 只作提示；**不禁用派发、不改 `canDispatch`**；徽标显示「无法判定」与「N 分钟前探测」；grok 断网走超时判 `unknown` 而不是 `logged_out`；`parser='none'` 的 agent（dsh）不起进程、不写缓存、DTO 的 `login` 为 null 且 UI 不渲染徽标 |
| 归属模块 | [[M4]] |
