# E-253　dsh 全程无流式事件

| | |
|---|---|
| 触发条件 | dsh 只有 `--profile headless`，跑完才给最后一条 assistant 文本，中途没有任何可归一化的 `session/update` 事件 |
| 期望行为 | 能力位新增 `hasStreamingEvents`，dsh 置假。**禁止伪造中间事件充数**：运行轨对该 agent 只显示「已派发 → 运行中 → 完成/失败」三段，逐步耗时退化为整段耗时，日志栏在运行期显示「该 agent 不提供过程输出，完成后一次性写入」。UI 按能力位灰掉「逐步展开」而不是留个永远空的列表（与 E-117 同一手法） |
| 归属模块 | [[M4]] |
