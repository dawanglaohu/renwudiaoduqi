# E-274　收口输出不合八段

| | |
|---|---|
| 触发条件 | 收口运行的最终文本缺任一段、段头顺序找不齐、或条目格式不合 |
| 期望行为 | 按「收口未完成」处理：保留原文可读、不做部分解析、不猜；收口运行转 `awaiting_human` 并开批次级收口闸门，批次 `needs_attention`，不计入自动轮次 |
