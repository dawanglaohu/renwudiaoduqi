# E-270　图形界面或自启进程找不到 shell 中已安装的 agent

| | |
|---|---|
| 触发条件 | agent 只通过 `.zshrc`、`.bashrc` 等 shell 启动文件加入 `PATH`，而 macOS/Linux GUI 或服务没有继承这些变量 |
| 期望行为 | 先使用用户配置的绝对路径，再检查平台级固定候选目录；仍找不到时列出已检查位置并要求用户选择文件，不读取、不执行用户 shell 启动文件 |
| 归属模块 | [[M1]] |
