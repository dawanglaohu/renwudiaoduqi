# E-333　泳道数据的取数与缓存

| | |
|---|---|
| 触发条件 | 前端拉 `lanes[]` 或收到泳道事件 |
| 期望行为 | `api/lanes.ts` 调既有 `GET /snapshot?docId` 只取 `.lanes`，`latestEventId` 与其余键一律丢弃、不写 `connection-store.lastEventId`；快照缺 `lanes` 键或不是数组 → 运行甲板显示「泳道数据不可用」并按 E-26 不自算槽位，不回退到按运行分流的旧布局；同一 tick 内连续到达 `lane.released` 与 `lane.assigned` → `resource-cache` 对同一 key 的在途请求合并只发一次，失效发生在请求已发出之后则响应到达后必须再拉一次；`lane.assigned` 同时失效 `lanes` 与 `runs` 时两个 fetcher 各自请求，不从快照里取 `runs` |
