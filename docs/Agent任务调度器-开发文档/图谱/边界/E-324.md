# E-324　手机端的泳道

| | |
|---|---|
| 触发条件 | 手机档（phone／phone-xs）打开运行甲板且窗口数 N＞1 |
| 期望行为 | 不并排、不横向滚动（E-145）：沿用单栏切换，一次只看一条泳道；顶部 44px 运行条「泳道 k/N · 〈taskKey〉 · 状态字形+文字」两端各一个 ≥44×44 的 ◀ ▶ 切换按钮，N=1 时禁用不隐藏；非当前泳道转「等你」计入全局未处理徽标，点徽标打开既有运行列表抽屉、每行一条泳道；当前泳道补位时跟随新任务、不跳去别的泳道；窗口数调小后 N 显示现存泳道数，泳道消失后落到 min(k, N′)；当前泳道号存 `selection-store` 内存，不进 URL、不持久化；收口运行占的泳道同样单流显示，不出「收口」按钮 |
