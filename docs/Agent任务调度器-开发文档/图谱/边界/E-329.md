# E-329　查 bug 运行的 git 禁令与 diff 基线

| | |
|---|---|
| 触发条件 | 组装查 bug 提示词与判定 FIXED |
| 期望行为 | 包装说明与收口共用同一禁令常量（禁 `git commit/push/checkout/branch/worktree/stash/merge/rebase/reset`、`gh` 任何子命令、文档脚本、改 `docs/`），再加阶段专属覆盖「修完不提交、不推送、不点审查，产品会通知审查会话再审」，FIXED 条目格式覆盖为「B〈n〉 → 改了什么、加了哪个测试」；派查 bug 时记起点树（HEAD SHA 与工作区树对象），FIXED 判定、再审 diff 与「自审查 pass 以来工作区 diff」都以它为基线；agent 违禁 commit 不拦截（E-75）且基线不受影响、不误判无改动；违禁 push 在凭据层失败（E-138）；未提交改动照 E-301 判未进 HEAD，落地清单照 E-74 列出 diff 摘要；查 bug 后人工打回时返工文本头部附「工作区已有查 bug 阶段未提交改动 N 个文件，先看 git status 再改」 |
