# E-206　清理候选集越界

| | |
|---|---|
| 触发条件 | 候选集里混进了任务记录或三段快照 |
| 期望行为 | 候选集只能由 M6 按「自己捕获的运行输出」目录白名单枚举生成；**M1 收到白名单目录之外的删除请求一律拒绝执行并记违规日志** |
| 归属模块 | [[M1]] |

## 被这些任务兜底

- [[M1-T5]]　磁盘占用统计、写满兜底与受限删除原语
