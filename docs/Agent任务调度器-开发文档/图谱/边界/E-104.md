# E-104　存储盘写满

| | |
|---|---|
| 触发条件 | 追加写失败 |
| 期望行为 | 立即停止新派发并明确报错；恢复后要能继续追加，已有记录不得损坏 |
| 归属模块 | [[M1]] |

## 被这些任务兜底

- [[M1-T5]]　磁盘占用统计、写满兜底与受限删除原语
