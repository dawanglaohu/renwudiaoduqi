# E-366　接管旧的活动批次或手动入口绕过文档计划

| | |
|---|---|
| 触发条件 | 开始时已有单批运行、多个活动批次，或自动执行期间手动启动别批 |
| 期望行为 | 最早未完成的一批已有活动运行则接管不重复；多个旧活动批次明确拒绝并列出；手动批次入口不能越批或绕过文档暂停 |
| 归属模块 | [[M8]] |

## 被这些任务兜底

- [[M8-T12]]　文档执行计划持久化、控制接口与快照
- [[M8-T13]]　开始后的批次自动接力与窗口调度
