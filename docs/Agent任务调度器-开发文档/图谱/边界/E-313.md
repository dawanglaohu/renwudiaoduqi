# E-313　点击阶段节点

| | |
|---|---|
| 触发条件 | 用户点泳道阶段链上的任一阶段节点（含历史行展开后的节点） |
| 期望行为 | 打开该阶段对应运行的详情 `#/run/〈runId〉`，不是任务详情；一个阶段有多次运行（E-112 恢复产生的新运行）时打开最近一次，更早的在运行详情里展开（E-27）；返工回环节点打开对应轮次的审查运行；`runId` 来自 daemon 的 `lanes[]` 与该任务的运行列表，前端不推算 |
