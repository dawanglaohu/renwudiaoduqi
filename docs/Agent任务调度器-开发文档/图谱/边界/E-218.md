# E-218　浏览器 Ctrl+F 搜不全

| | |
|---|---|
| 触发条件 | 用户在几十 MB 会话里按 Ctrl+F |
| 期望行为 | 浏览器只搜到当前已加载分段；会话视图**必须另给一个显式的「在整个会话中查找」入口**，否则用户会误以为已搜全文 |
