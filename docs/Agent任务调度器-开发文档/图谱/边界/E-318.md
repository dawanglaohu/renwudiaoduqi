# E-318　流水线设置存储缺行或损坏

| | |
|---|---|
| 触发条件 | `settings` 表无 key=pipeline 行，或 `value_json` 非法／含未知值 |
| 期望行为 | 缺行返回内置默认 `{bughunt: 0, wrapupMode: 'auto', reviewOverride: null, wrapupAssignment: {mode: 'follow'}}` 不插行；旧库只有两键的合法行（恰好 `bughunt`+`wrapupMode`，形状正确）读侧补全另两键默认值，不改库；非法或含未知字段的行整体回落默认并 warn，不退出、不覆盖坏值直到下一次 PATCH；PATCH 四键整体写入（`{bughunt, wrapupMode, reviewOverride, wrapupAssignment}`），缺任一键或值非法返回 `E_VALIDATION`；写成功发 `settings.pipeline_changed{pipeline}`（完整四键）让另一端刷新 |
| 归属模块 | [[M8]] |
