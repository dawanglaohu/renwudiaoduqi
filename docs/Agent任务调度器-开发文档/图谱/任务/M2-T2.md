# M2-T2　设备配对、令牌哈希与吊销

- 所属模块：[[M2]]　**接入与设备信任**——定义两端如何连上 daemon 并不丢事件地保持同步：一次性配对码与可单独吊销的设备令牌、鉴权与操作归属、REST 骨架与 API 版本、SSE 服务端的事件信封／重放窗口／保活，以及自写的 SSE 客户端。凡「谁能连上、连上之后按什么协议收发」的都归它
- 前置依赖：[[M2-T1]]
- 完成后解锁：[[M2-T3]]、[[M9-T15]]

## 输入 / 产出

- **输入**：M2-T1 的插件链
- **产出**：`service/pairing.ts`、`repo/devices.ts`、`/pair/*` 与 `/devices/*` 路由

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 配对码一次性、TTL ≤60 秒、只在内存
用掉或过期即失效（[[E-07]]）
2) 令牌只存 `scrypt` 哈希 + 随机盐，比对用 `timingSafeEqual`，库中无明文
3) 吊销后该设备的活动连接立即断开并返回 401（[[E-127]]）
4) `/pair/*` 每 IP 每分钟 10 次，超限 429 **并立即作废当前配对码**（[[E-07]]）
5) 零已配对设备时把一次性配对码打印到控制台并写入数据目录 `pairing-code.txt`（0600，用后即删），**不新增第四个免鉴权端点**（[[E-226]]）

## 必须处理的边界

- [[E-07]]　配对码泄露或重复使用
    - 触发：配对码被第三方获取
    - 期望：配对码一次性且短时效（≤60 秒），配对后换发长期设备令牌；令牌按设备列出并可单独吊销
- [[E-127]]　设备丢失或令牌泄露
    - 触发：手机丢了
    - 期望：桌面端能列出已配对设备并一键吊销；吊销后该设备的活动连接立即断开
- [[E-226]]　**全新装机的自举困境**
    - 触发：零已配对设备、两个壳都未就绪，而 `POST /pair/code` 需 device 令牌
    - 期望：daemon 必须能把一次性配对码**输出到本机控制台或数据目录文件**（能读它就等同已拥有 daemon 全部权限）；**不得为此新增第四个免鉴权端点**，E-08「不存在局域网免鉴权分支」不动
