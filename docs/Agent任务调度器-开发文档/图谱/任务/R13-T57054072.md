## 实施沉淀

<!-- notes:begin -->
1. 实现选择：
   - 采用 Playwright Chromium 驱动真实 Web 构建产物（dist/index.html），通过独立进程拉起真实 daemon bootstrap.mjs，严格杜绝任何 mock、测试钩子（window.__setToken）或 SQLite 直写，完全通过公开 HTTP/SSE API 与 UI 交互完成端到端全链路闭环。
   - 针对 Step 8（离线断网、重连与 Last-Event-ID），若直接调用 page.reload 会刷新 SPA 内存重置 sseClient 闭包中的 lastEventId，且 context.setOffline 不会立刻 reset 既有 HTTP 长连接 socket。最终方案通过 `page.evaluate(() => window.stop())` 配合 `page.route` 拦截重连，在零页面重载、零组件卸载、完全保留内存 lastEventId 和 DOM 的前提下立即注入网络故障触发指数退避，完美闭环验证离线横幅、客户端断网期间后端 ring-buffer 消息入队、恢复网络后请求头携带 `Last-Event-ID` 补推且去重。
   - 针对 Vitest 多测试文件并发争抢 `%ProgramData%/agent-scheduler/daemon.lock` 实例锁的问题，在 `vitest.e2e.config.ts` 中配置 `fileParallelism: false` 与 `maxConcurrency: 1`，保证冒烟测试单并发顺序执行与环境彻底清理。

2. 维护约束：
   - E2E 运行产物（日志、快照、DOM 与截图）统一脱敏写入 `e2e/artifacts/`，受 `.gitignore` 保护不进仓库，且受 `biome.json` 排除以避免污染根 check。
   - 契约验证断言 DOM 呈现与公开 API 查询的一致性，不可脱离公开接口做推断。
