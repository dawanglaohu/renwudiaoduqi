# M2-T3　鉴权中间件与免鉴权白名单

- 所属模块：[[M2]]　**接入与设备信任**——定义两端如何连上 daemon 并不丢事件地保持同步：一次性配对码与可单独吊销的设备令牌、鉴权与操作归属、REST 骨架与 API 版本、SSE 服务端的事件信封／重放窗口／保活，以及自写的 SSE 客户端。凡「谁能连上、连上之后按什么协议收发」的都归它
- 前置依赖：[[M2-T2]]
- 完成后解锁：[[M2-T5]]

## 输入 / 产出

- **输入**：M2-T2 的令牌体系
- **产出**：`http/plugins/30-auth.ts`、白名单常量数组

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 鉴权 hook 注册在 `/api/v1` 子 scope 内部而非根实例，静态资源不被拦、后注册路由不漏
2) 免鉴权白名单只有 `/health`、`/pair/claim`、`/version` 三条且写死在常量数组里
3) **代码中不存在任何基于 remoteAddress／网段／`isPrivateIp` 的绕过分支**（[[E-08]]）
4) 401/403 复用同一响应信封并给出 `E_UNAUTHORIZED` / `E_DEVICE_REVOKED` 明确 code
5) `AGSCHED_DEV=1` 不改变任何鉴权行为，仅影响错误响应带不带 stack
6) 每条写操作记录 `actorDeviceId`（谁派的、谁中止的、谁回的话），系统发起记 `null`
将来加人不必迁移历史数据（[[E-128]]）

## 必须处理的边界

- [[E-08]]　daemon 被隧道暴露到公网
    - 触发：用户自行接入 Tailscale/frp
    - 期望：鉴权与加密默认开启；代码中不得存在「局域网内免鉴权」分支
- [[E-128]]　操作归属不明
    - 触发：多设备下不知道是谁派的
    - 期望：记录里保留 `actorDeviceId`（谁派的、谁中止的、谁回的话），将来加人不必迁移历史数据
