# M4-T6　模型与思考强度的粒度与透传

- 所属模块：[[M4]]　**Agent 适配**——把形态各异的 agent 抽象成同一个可派发对象：注册表（含每个 agent 通用的版本指纹探测字段与具名的「适配器种类」枚举）、可执行探测、模型清单读取与降级、启动参数与三档权限映射、以各家原生通道为主干把输出归一化成 ACP `session/update` 词汇的事件、可回话与**是否提供流式事件**等能力位，并自实现一个通用 ACP 适配器作为兜底与第 6 家及以后的入口。凡「某一家 agent 跟别家怎么不一样」的都归它
- 前置依赖：[[M4-T5]]
- 完成后解锁：[[M9-T18]]

## 输入 / 产出

- **输入**：M4-T5 的清单
- **产出**：默认模型／思考强度与单任务覆盖的取值链

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 每 agent 一个默认 + 单任务可临时覆盖
覆盖只作用于这一次派发及其重试，**绝不回写任何 agent 的配置文件**
2) 清单为空时允许留空表示「跟随 agent 配置」，派发不传 `--model`，不禁用该 agent（[[E-35]]、[[E-41]]）
3) 模型名含空格、引号或 shell 元字符时以数组形式传给子进程（[[E-42]] 的对偶面）
4) 别名与完整 ID 并存时都原样透传，**不做别名映射、不做去重合并、不做跨家等价映射**（[[E-45]]、[[E-30]]）
5) 设过覆盖的任务重试时沿用上次实际使用的模型，只有显式清除才回落默认（[[E-33]]）
6) 切换执行 agent 时清空模型覆盖并回落新 agent 默认，下拉只列当前 agent 的清单（[[E-34]]）
7) **思考强度走与模型完全同构的取值链**（每 agent 默认 + 单任务覆盖 + 重试沿用 + 切 agent 清空），落 `runs.effort_tier`（决策 52）
8) 不支持思考强度的 agent 置 NULL、派发不传任何相关参数、UI 显示「—」，**不补默认档冒充**，也不因此禁用该 agent（[[E-254]]）
9) 档位超出该模型取值域时派发前校验并就地说清原因与改法，**不静默降档也不静默丢弃**
校验不了时按「不支持」处理（[[E-255]]）

## 必须处理的边界

- [[E-254]]　agent 不支持思考强度
    - 触发：dsh 无对应参数；某些模型或某些 agent 版本也没有
    - 期望：该 agent 的思考强度置 NULL、**派发时不传任何相关参数**，UI 一律显示「—」并在 title 说明原因。**绝不补一个默认档冒充**——补了等于谎称控制生效（与 E-26「数据缺失显示—，不拿 0 冒充」同理）。不因不支持而禁用该 agent（与 E-35 对称）
- [[E-255]]　思考强度档位无效或超出该模型取值域
    - 触发：用户选了高档但该模型只接受 low/medium；或厂商改了取值域
    - 期望：派发前校验，不通过则**就地说清原因与改法**（「`gpt-5.6-mini` 不接受思考强度 `高`，可选 低/中」），不静默降档也不静默丢弃；校验不了时按「不支持」处理走 E-254
- [[E-30]]　模型名无权限或已改名
    - 触发：从配置文件读到的模型实际不可用
    - 期望：派发前做一次轻量校验并明确指向「模型配置问题」；绝不做跨家模型等价映射，每个 agent 只用它自己配置里读到的名字
- [[E-33]]　设了覆盖模型的任务重试
    - 触发：任务上设过模型覆盖，随后重派
    - 期望：沿用该任务上次实际使用的模型（记在任务快照里），不回落 agent 默认；只有用户显式清除覆盖才回落
- [[E-34]]　任务切换执行 agent
    - 触发：用户把某任务从 codex 改派给 grok
    - 期望：清空该任务的模型覆盖并回落新 agent 的默认；模型下拉只列当前 agent 的清单，不允许跨家残留
- [[E-35]]　从未设过默认模型
    - 触发：首次使用，agent 默认模型为空
    - 期望：不阻塞派发，派发时不传 `--model`，UI 标注「跟随 agent 配置」，而不是弹窗强制先去设置
- [[E-41]]　模型清单最终为空
    - 触发：配置无值、命令不可用、用户未手填
    - 期望：允许留空表示「跟随 agent 自身配置」，派发时不传 `--model`，而不是禁止使用该 agent
- [[E-42]]　模型名含 shell 元字符
    - 触发：模型名带空格、引号或 `;` `&` 之类
    - 期望：参数以数组形式传给子进程，任何情况下不拼接 shell 字符串
- [[E-45]]　别名与完整模型 ID 并存
    - 触发：claude 的 `opus`/`sonnet` 别名与完整 ID 同时出现在清单
    - 期望：两者都原样透传，不做别名映射、不做去重合并
