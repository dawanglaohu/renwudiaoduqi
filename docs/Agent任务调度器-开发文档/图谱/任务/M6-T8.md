# M6-T8　会话分段回读与厂商会话引用

- 所属模块：[[M6]]　**运行监管**——管一次运行从启动到结束的全过程：状态机（「已退出」与「已落地」分开）、收流与落盘编排、按游标分段回读与厂商会话文件的只读引用、进度信号、停滞检测、中止与 daemon 重启后的对账、回话投递；任务到达终态后结束并归档该任务全部会话（进程还在走 `killTree` 两阶段），归档后会话引用只读、不得复用，也归它。凡「这一次运行现在怎么样、它说过什么」的都归它
- 前置依赖：[[M6-T2]]、[[M1-T4]]
- 完成后解锁：[[M6-T9]]

## 输入 / 产出

- **输入**：M1-T4 的偏移索引
- **产出**：`GET /runs/:id/log`、`vendorSessionRef`

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 厂商会话文件**只读打开、只存路径与偏移**，任何清理策略永不删除或改写它们（[[E-96]]）
2) 厂商会话文件已不在磁盘时显示「原始会话已不在磁盘（附路径）」，仍正常展示自己捕获的输出与三段快照，不报错不崩（[[E-97]]）
3) 单会话超 20MB 或 50 万字时默认只加载尾部并给「向上加载更多」，并提供「用系统默认程序打开原始文件」（[[E-98]]）
4) 双端游标分页（`fromSeq` + `direction`），向上翻历史与向下跟随都可用
5) 跨设备推到手机前对会话内容做基本脱敏，或在首次开启远程查看时明确告知（[[E-25]]）
6) 不依赖「厂商 GUI 里也能看」这一假设——**本产品自己的会话查看界面即唯一入口，必须做完整**（[[E-32]]）

## 必须处理的边界

- [[E-25]]　会话内容含密钥
    - 触发：agent 打印了环境变量或 token
    - 期望：跨设备推到手机前做基本脱敏，或至少在首次开启远程查看时明确告知
- [[E-32]]　桌面端会话不共享
    - 触发：claude 桌面端若不与 CLI 共享会话（codex 已确认共享，claude 未确认）
    - 期望：调度器自己的会话查看界面即唯一入口，必须做完整，不得指望用户「去 GUI 里看」
- [[E-96]]　厂商会话文件的所有权
    - 触发：会话记录位于 `~/.claude/projects`、`~/.codex/sessions` 等厂商目录
    - 期望：只读打开、只存路径与偏移；任何清理/归档策略永不删除或改写这些文件（删了会破坏 `claude --resume` 之类的原生续接）
- [[E-97]]　厂商会话文件已不在
    - 触发：用户在别处删除或轮转了它
    - 期望：详情页显示「原始会话已不在磁盘（附路径）」，仍正常展示自己捕获的输出与三段快照，不报错、不崩
- [[E-98]]　单会话体积超阈值
    - 触发：超过 20 MB 或 50 万字
    - 期望：默认只加载尾部片段，顶部给「向上加载更多」，并提供「用系统默认程序打开原始文件」

## 实施沉淀

<!-- notes:begin -->
- **只读所有权（E-96）**：厂商会话文件（如 Claude/Codex 原生项目会话）属于第三方工具。调度器仅在数据库保存其路径字符串与偏移，读取时使用严格只读文件描述符（`r` 模式），且任何清理、归档和截断逻辑的白名单绝对排除厂商目录，避免破坏原生 CLI 恢复能力。
- **文件丢失降级（E-97）**：用户在外部清理厂商文件属正常情况。服务层不依赖厂商文件可用性，遇到缺失静默标记并回落，在输出首部注入明确通知行，并自动装配派发时的输入/产出/验收三段快照与调度器自建 raw/events 日志，保证历史完整可查。
- **超限保护（E-98）**：20MB 或 50 万字大文件默认仅分页加载最后一段尾部窗口，防止大响应击穿移动端网络和前端虚拟列表初始化。游标双向解耦，向上翻页使用 `prevCursor` 请求前置窗口；「用系统默认程序打开」只产出结构化的 `{file, args[], cwd}`，不拼命令串——路径首选来源是厂商会话引用，出自 agent 输出、不可控，交给 shell 会变成注入面。
- **按段有界回读（R2）**：回读不整文件加载，而是消费 M1-T4 的 `log_segments` 偏移索引拿到各段 `fileSeq/path/byteStart/byteEnd/lineCount`，用 `formatCursor/parseCursor` 编解码「段号:字节偏移」游标，单次读取不超过 `READ_CHUNK_LIMIT_BYTES`。响应里的 `totalLines` 是全会话行数（各段 `lineCount` 之和）而不是本次窗口大小；仍在追加、尚未入索引的段行数未知，此时回落窗口行数，不谎报总数。
- **密钥脱敏（E-25）**：移动端和跨设备推送时针对常见 Authorization、环境变量、私钥与知名 Token 模式执行过滤替换，并在日志流首部输出安全提示告知远程查看已启用保护。
<!-- notes:end -->
