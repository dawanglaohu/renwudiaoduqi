# M4-T2　参数模板校验与模板变量白名单

- 所属模块：[[M4]]　**Agent 适配**——把形态各异的 agent 抽象成同一个可派发对象：注册表（含每个 agent 通用的版本指纹探测字段与具名的「适配器种类」枚举）、可执行探测、模型清单读取与降级、启动参数与三档权限映射、以各家原生通道为主干把输出归一化成 ACP `session/update` 词汇的事件、可回话与**是否提供流式事件**等能力位，并自实现一个通用 ACP 适配器作为兜底与第 6 家及以后的入口。凡「某一家 agent 跟别家怎么不一样」的都归它
- 前置依赖：[[M4-T1]]
- 完成后解锁：[[M9-T14]]

## 输入 / 产出

- **输入**：M4-T1 的注册表
- **产出**：模板解析器与保存时校验

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 只允许 `{model}` `{prompt_file}` `{cwd}` `{session_dir}` 四个模板变量
含未知模板变量或括号未闭合时**保存即拒绝**并高亮出错位置（[[E-89]]）
2) 注册表只发布模板校验通过的快照，运行时渲染入口仍须拒绝未经校验的模板
3) 两个 agent 配成同一可执行路径时允许
会话目录相同则产生 `reason` 精确等于 `session-dir-overlap` 的英文告警但不拒绝保存，中文文案由设置页映射为「会话记录可能互相覆盖」（[[E-95]]）

## 必须处理的边界

- [[E-89]]　参数模板写错
    - 触发：含未知模板变量或括号未闭合
    - 期望：保存时即校验并拒绝，高亮出错位置；运行时永不使用未通过校验的模板
- [[E-95]]　两个 agent 配成同一路径
    - 触发：用户复制配置后没改
    - 期望：允许；会话目录若也相同，daemon 产生 `reason` 精确等于 `session-dir-overlap` 的英文告警但不拒绝保存，设置页按该原因显示「会话记录可能互相覆盖」

## 实施沉淀

<!-- notes:begin -->
- 模板变量仅限定为 `{model}`、`{prompt_file}`、`{cwd}`、`{session_dir}` 四个，不使用全局正则模糊替换，而是采用单字符遍历状态机。正则全局替换难以精确定位嵌套花括号或未闭合花括号的首字符位置，无法给出准确的行内下划线定位。
- 运行时渲染入口强制前置断言校验，通过 `ValidatedLaunchTemplate` 类型拦截未校验模板。未指定 model 时按 E-35 / M4-T6 规范剔除 `--model` 与 `{model}` 参数对，而不强塞空串或报语法错误；其余白名单变量若模板已引用但上下文缺失则一律以 `E_VALIDATION` 阻断，避免带未展开占位符启动子进程。
- E-95 的可执行路径比对通过跨平台斜杠归一化与 Windows 驱动器前缀不区分大小写比较；会话目录判定优先提取参数模板中显式 `--session-dir` 参数，未指定时归入基于可执行程序的默认会话空间。同路径且同会话目录只产生告警，不拒绝保存，兼顾用户复制配置场景与覆盖预警。
- domain 层严格保持零副作用纯函数设计，不直读 `process.platform` 与环境变量，路径比对统一基于纯字符串规则归一化，确保测试确定性与跨平台一致性。
<!-- notes:end -->
