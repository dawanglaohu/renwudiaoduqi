## 实施沉淀

<!-- notes:begin -->
- 桌面扩展以增加列数和内容宽度为主；操作面表单列与侧栏合计 1112px，放不下时侧栏排在表单之后。设备列表、配对码与网络地址继续使用同一个状态 Hook，移动栏位不改变令牌、当前设备识别或吊销流程。
- 手机间距保留无前缀基准，桌面断点只收紧。设置卡片的桌面外壳允许 18px，手机用较窄断点收为 16px；加载与空态按所属区域展示，内边距不超过 14px。
- 间距守护以 TypeScript 语法树读取每个类串和条件分支，注释不参与匹配；二元 + 保留原字符串边界，模板、join 和 cn/clsx/classNames 内的拼接也参与检查，各条件分支独立比较。轴向类优先于全向类，不能借另一元素的间距作为基准；没有基准的任意断点间距也拒绝。
- 可确定的 calc 间距按 px/rem 统一求值，支持加减乘除、括号和已知间距 token，不执行源码。8px 到 calc(4px*4) 的 16px 必须命中；相等与收紧放行，浮点舍入不算增长。未解析 token、循环引用、除零和不合法量纲保留为未知值。
- 居中宽度豁免以完整源文件路径限定到配对容器与连接失败页。同名文件、路由未使用的旧组件和列表页都不能继承豁免。
