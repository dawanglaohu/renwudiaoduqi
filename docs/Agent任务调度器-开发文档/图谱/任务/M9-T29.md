## 必须处理的边界

- [[E-145]]　极窄屏布局
    - 触发：手机竖屏宽度 < 400px
    - 期望：同一套代码降级为单栏切换（任务列表 / 运行流 / 详情），不得出现横向滚动或并排三栏

    - 期望：启动即归一化为 `#/`，**不得出现无 hash 的中间态白屏**
