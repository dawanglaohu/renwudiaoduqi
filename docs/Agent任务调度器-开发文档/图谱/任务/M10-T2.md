# M10-T2　桌面壳（Tauri v2）

- 所属模块：[[M10]]　**桌面壳与手机壳**——只做窗口与单实例、系统通知、令牌安全存储三件事的两个原生容器，外加 daemon 未运行时的引导与运行时缺失检测。壳按界面声明的可选桥接接口去实现，界面在没有壳时按能力探测降级，因此依赖方向恒为壳→界面
- 前置依赖：[[M10-T1]]、[[M1-T6]]
- 完成后解锁：[[M10-T4]]

## 输入 / 产出

- **输入**：M10-T1 的契约；M1-T6 的自启机制
- **产出**：`packages/shell-desktop/`

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 只做窗口与单实例、系统通知、令牌安全存储三件事
**壳内不出现 task/run/gate/batch/agent 任何业务词**
2) daemon 未运行时显示连接失败页 + 「启动 daemon」按钮，**壳自身不内嵌任何调度或重试策略**（[[E-146]]）
3) 缺少 WebView2 运行时时启动检测并给出安装引导，**不得白屏**（[[E-148]]）
4) 触发自启注册：每次启动校验注册项路径与当前可执行文件一致，不一致则重写
重写失败降级为「需手动启动」并给可复制命令（[[E-209]]）
5) 用户手动关掉自启项时只检测并询问，**不静默重注册**，询问带「不再提醒」（[[E-208]]）
6) 通知点击以 `#/run/〈runId〉` 交给 WebView，**不做自定义 IPC 传业务数据**

## 必须处理的边界

- [[E-146]]　桌面壳启动时 daemon 未运行
    - 触发：壳先于服务启动
    - 期望：显示连接失败页 + 「启动 daemon」按钮（调用外部已安装的启动命令）；壳自身不内嵌任何调度或重试策略
- [[E-148]]　缺少 WebView2 运行时
    - 触发：Windows 上未安装 WebView2
    - 期望：启动时检测并给出安装引导，不得白屏
- [[E-208]]　用户关掉了系统自启项
    - 触发：外部禁用了自启
    - 期望：壳下次启动**只检测并询问「是否重新注册」，不静默重注册**；询问带「不再提醒」选项
- [[E-209]]　升级后自启项指向旧路径
    - 触发：安装包升级
    - 期望：`register` 必须**幂等且接受可执行文件路径**；壳每次启动校验注册项与当前可执行文件一致，不一致则重写；重写失败降级为「需手动启动」并给出可复制命令
