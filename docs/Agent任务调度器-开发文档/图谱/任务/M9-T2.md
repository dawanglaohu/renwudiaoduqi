# M9-T2　形状枚举与状态徽标

- 所属模块：[[M9]]　**客户端界面**——两端共用的那一套界面本身：多流监看、会话查看、审批与闸门、设置与配对、落地清单、按批次折叠的批次树与执行行呼吸灯，以及同一套代码的窄屏降级。它只通过 M2 的契约与 daemon 通信，**界面里不含任何业务判定**（折叠默认值与「能否收口」都是 daemon 给的字段）
- 前置依赖：[[M9-T1]]
- 完成后解锁：[[M9-T7]]、[[M9-T19]]

## 输入 / 产出

- **输入**：11 节的形状表与状态表
- **产出**：`lib/spine-shape.ts`（内联 SVG path）、`components/status-badge.tsx`

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 12 个形状为单色描边内联 SVG，一律 `currentColor`，**path 中无颜色字面量**（[[E-231]]）
2) 「失联」「审查未完成」「未识别／降级」各有**专属形状**，绝不复用 `✕`，不允许只靠颜色区分（[[E-230]]）
3) 统一 viewBox + `vector-effect:non-scaling-stroke`
在 Windows 125%/150% 缩放与一台 Android 真机上各看一次，形状不糊（[[E-232]]）
4) 每个形状带中文 `aria-label`，灰度打印下仍可区分（[[E-233]]、[[E-110]]） 4b) 形状在浅色下靠**形状本身**区分，**不依赖深色下的发光或光晕**
形状枚举两模式逐一对应（[[E-172]]）
5) 形状表与状态枚举一一对应且可机检，不允许「先上线后补形状」（[[E-234]]）
6) 徽标为矩形非药丸，恒为「字形 + 文字」，颜色是第三层信息

## 必须处理的边界

- [[E-110]]　长时间盯屏与色觉差异
    - 触发：用户连续监看数小时，或投屏/色弱
    - 期望：深色为默认，日志用等宽字体；状态区分不能只靠色相，必须同时有形状或文字
- [[E-172]]　形状依赖深色发光
    - 触发：运行轨形状在浅色下分不清
    - 期望：改形状本身，不为浅色单开一套形状；形状枚举必须两模式逐一对应
- [[E-230]]　有状态没有专属字形
    - 触发：「失联」「审查未完成」「未识别/降级」这些态不等同于「失败」
    - 期望：形状枚举必须为它们**各补一个专属形状**，绝不复用 `✕`，更不允许只靠颜色区分
- [[E-231]]　SVG 里写死颜色
    - 触发：path 中出现颜色字面量
    - 期望：一律 `currentColor`，颜色只由外层 token 决定（11 节禁令 24）
- [[E-232]]　非整数 DPR 下形状糊
    - 触发：Android 2.75x、Windows 125%/150% 缩放，11–13px 小尺寸
    - 期望：统一 viewBox + `vector-effect: non-scaling-stroke`；**验收须在 125%/150% 缩放与一台真机上各看一次**，糊成一团即判不合格
- [[E-233]]　屏幕阅读器与灰度打印
    - 触发：无颜色可依
    - 期望：每个形状必带中文 `aria-label`；11 节那张字符表**降级标注为「语义来源与 aria 文案来源」**，不再是渲染实现
- [[E-234]]　新增状态没配形状
    - 触发：状态枚举加了一项
    - 期望：形状表与状态枚举**必须一一对应且可机检**，不允许「先上线后补形状」

## 实施沉淀

<!-- notes:begin -->
- 架构分层收敛：`src/lib/` 遵循零 React 依赖的硬规则，将形状定义建模为可序列化的纯数据结构 `SpineShapeDefinition` 与纯函数 `renderSpineShapeSvg`；React JSX 节点转换与 UI 呈现完全收敛在 `src/components/status-badge.tsx` 中。
- 形状独立性判据（E-230、E-110）：状态区分绝不能依赖色相，更不能依赖深色发光或辉光（E-172）。失联（断开双环链扣 ⚯）、审查未完成（放大镜内嵌横杠 🔍）、未识别（虚线圆环内嵌问号 ？）三态必须具备互不重叠的拓扑几何特征，绝不降级复用对角叉号 ✕；灰度复印或 0% 饱和度下 12 种状态轮廓两两相异。
- 消除非整数 DPR 模糊（E-232）：全部形状统一收敛至 `viewBox="0 0 16 16"`，关键控制点定位于整数或半整数网格，且每个 SVG path/rect/circle/line 强制声明 `vectorEffect: "non-scaling-stroke"`，防止在 125%/150% Windows 缩放或 Android 2.75x 屏幕下缩放导致 1.5px 笔触失真或粘连。
- 1:1 枚举机检防线（E-234）：TypeScript 类型 `Record<StatusState, SpineShapeDefinition>` 与单测做双重闭环校验，新增状态但未补齐形状定义将直接在 `tsc -b --noEmit` 与 Vitest 中硬失败，杜绝「先上线后补形状」。
- 徽标仪表规范（AC 6）：徽标高度固定为 20px、圆角固定为 6px（矩形），绝对禁止圆角药丸 `rounded-full`；`stopped` 状态显式绑定 `borderStyle: dashed`，`partial` 绑定暖色 `--warn` 且严禁染绿。
