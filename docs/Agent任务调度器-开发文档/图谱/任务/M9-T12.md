# M9-T12　手机端布局与拇指区

- 所属模块：[[M9]]　**客户端界面**——两端共用的那一套界面本身：多流监看、会话查看、审批与闸门、设置与配对、落地清单、按批次折叠的批次树与执行行呼吸灯，以及同一套代码的窄屏降级。它只通过 M2 的契约与 daemon 通信，**界面里不含任何业务判定**（折叠默认值与「能否收口」都是 daemon 给的字段）
- 前置依赖：[[M9-T9]]
- 完成后解锁：[[M9-T13]]

## 输入 / 产出

- **输入**：11 节的手机规格
- **产出**：`thumb-bar.tsx`、单栏切换

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 手机竖屏 <400px 降级为单栏切换（任务列表／运行流／详情），**不得横向滚动或并排三栏**（[[E-145]]）
2) 停止与批准固定在拇指区、分置两端或间距 ≥24px、各 ≥44×44px，**不随日志滚动移出视野**（[[E-107]]）
3) 单栏切换到「任务列表」时若某条流转「等你」，必须有可见的未处理计数徽标（[[E-240]]）
4) 手机端中止需二次确认防口袋误触（[[E-124]]）
5) 首屏加载量显著更小（尾部 32KB），不预取全量
切后台回前台不重拉全量（[[E-99]]）
6) 展开的 tool payload 走 bottom sheet 不内联
7) 批次表格在小屏降级为可折叠列表（[[E-13]]）
8) app 曾退到后台时重回前台拉未读列表，**等待中的确认项不过期、不自动放行**（[[E-58]]）

## 必须处理的边界

- [[E-107]]　手机小屏看运行流
    - 触发：竖屏单手操作
    - 期望：单流全屏 + 运行列表抽屉；停止与审批按钮固定在拇指区，不随日志滚动而移出视野
- [[E-124]]　手机端误触中止
    - 触发：口袋里误触
    - 期望：与桌面端同权限，但需二次确认
- [[E-13]]　手机竖屏看批次与并行窗口
    - 触发：小屏访问宽表格视图
    - 期望：降级为可折叠列表，不得让桌面宽表格横向滚动
- [[E-145]]　极窄屏布局
    - 触发：手机竖屏宽度 < 400px
    - 期望：同一套代码降级为单栏切换（任务列表 / 运行流 / 详情），不得出现横向滚动或并排三栏
- [[E-240]]　单栏切换藏住提醒
    - 触发：phone-xs 切到「任务列表」栏时某条流转成「等你」
    - 期望：必须有可见的未处理计数徽标，否则单栏切换恰好藏住用户唯一明确要求被提醒的事
- [[E-58]]　手机曾退到后台
    - 触发：无离线推送（决策 3），确认项在后台期间产生
    - 期望：重回前台拉未读列表；等待中的确认项不过期、不自动放行
- [[E-99]]　手机端打开大会话
    - 触发：小屏 + 移动网络
    - 期望：首屏加载量显著更小（如尾部 32 KB），不预取全量；切后台再回前台不重拉全量
