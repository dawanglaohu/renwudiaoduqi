## 实施沉淀

<!-- notes:begin -->
1. `elevate_once` 的非法状态错误由 MessageService 附 `operation` 标记，统一错误处理仅对此操作返回 409。其他状态机错误沿用原状态码，避免把内部故障误判为客户端冲突。
2. 缺少提升函数时记录未送达；提升函数或状态迁移失败时不写 delivered。消息持久化失败时清除本运行的内存提升标记。该补偿尚不能替代真实代理协议的授权回执与事务协调，见前置任务 [[R8-T89804121]]。
3. 权限受阻操作行位于运行日志滚动区内，按钮同步锁阻止重复提交。切换运行时清理界面状态，上一运行迟到的请求结果不能更新当前运行。
4. 已上传的 GIF 只证明浏览器向真实 daemon 发起过请求和按钮状态变化。录制脚本直接注入权限受阻及继续输出事件，没有真实代理执行，不能作为 E-133 同一运行继续的验收证据。须待 [[R8-T89804121]] 接通授权传输后，从最终代码重新录制。
