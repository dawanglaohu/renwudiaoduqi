## 实施沉淀

<!-- notes:begin -->
1. `elevate_once` 的非法状态错误由 MessageService 附 `operation` 标记，统一错误处理仅对此操作返回 409。其他状态机错误沿用原状态码，避免把内部故障误判为客户端冲突。
2. `elevate_once` 只消费正式 Codex app-server 进程发出的当前授权请求；按请求 ID 回答并等待 `serverRequest/resolved`，再迁运行状态与写 delivered。无会话、无待答请求、管道失败时返回类型化错误；消息持久化失败清除内存提升标记。会话随本运行结束，默认权限配置不变。
3. 权限受阻操作行位于运行日志滚动区内，按钮同步锁阻止重复提交。事件可能早于运行 DTO 的 awaiting_reply 状态到达，界面以真实待答请求 ID 与运行能力显示按钮，由服务端复核状态。切换运行时清理界面状态，上一运行迟到的请求结果不能更新当前运行。
4. 旧 GIF 直接注入事件，已失去验收效力。真实浏览器冒烟已使用新目录启动正式 daemon，经配对、文档导入、任务派发，让 Codex 在工作树外请求写入；浏览器点击后同一 runId 的代理写入目标文件并继续产出事件。全量 `pnpm -w check` 为 202 个测试文件通过、2478 项通过、4 项跳过。最终 PR 应以最终 HEAD 的重新录制 GIF 为准。
