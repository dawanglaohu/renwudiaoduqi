# M7-T4　rework 回灌与重试上限

- 所属模块：[[M7]]　**审查流水线**——对已结束的运行做「合不合格」的判定：先跑本地机械检查，通过后以只读档派一个 agent 跑文档给出的审查提示词，产出 pass / rework / doc-issue 并回灌 rework 意见。凡「判定一次运行的结果」的都归它
- 前置依赖：[[M7-T3]]、[[M6-T6]]
- 完成后解锁：无，它不卡别人

## 输入 / 产出

- **输入**：M7-T3 的判定；M6-T6 的注入通路
- **产出**：rework 循环

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) rework 意见经回话通路回灌原会话，重试计数 +1
**自动重试上限默认 2 次**，超限转「待人确认」，不无限自动改（[[E-55]]）
2) 回灌后 diff 反而缩小或回退时仍走同一套检查，计数照加，达上限转人（[[E-68]]）
3) 人工打回时必须能附一句话意见，该意见复用同一条 rework 通路（[[E-59]]）

## 必须处理的边界

- [[E-55]]　全自动下审查反复判 rework
    - 触发：审查连续不通过
    - 期望：重试上限默认 2 次，超限转「待人确认」，不无限自动改
- [[E-59]]　用户点「打回」
    - 触发：审查后人工判定需返工
    - 期望：必须能附一句话意见，该意见复用 rework 通路回灌原会话
- [[E-68]]　rework 后改动反而回退
    - 触发：回灌意见后 diff 缩小或撤回
    - 期望：仍走同一套检查，重试计数 +1，达上限转人
