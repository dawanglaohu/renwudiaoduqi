# M4-T5　四家模型清单读取与降级

- 所属模块：[[M4]]　**Agent 适配**——把形态各异的 agent 抽象成同一个可派发对象：注册表（含每个 agent 通用的版本指纹探测字段与具名的「适配器种类」枚举）、可执行探测、模型清单读取与降级、启动参数与三档权限映射、以各家原生通道为主干把输出归一化成 ACP `session/update` 词汇的事件、可回话与**是否提供流式事件**等能力位，并自实现一个通用 ACP 适配器作为兜底与第 6 家及以后的入口。凡「某一家 agent 跟别家怎么不一样」的都归它；登录态探测（三值、只跑 agent 自己的状态命令、结果缓存）与模型清单的四级来源合并（实时／配置／内置别名／历史）也归它——它们都是「这一家怎么问」的事
- 前置依赖：[[M4-T1]]
- 完成后解锁：[[M4-T6]]、[[M4-T14]]、[[M9-T14]]

## 输入 / 产出

- **输入**：04 节实测的四种配置格式
- **产出**：`readModels()` 四个具名解析器

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) codex TOML／claude JSON／grok TOML／pi models.json 四种格式各自读出清单
2) 列模型命令超 5 秒或退出码非 0 时降级为「配置文件当前值 + 历史用过 + 手填」并标「清单可能不全」，**绝不阻塞派发**（[[E-38]]）
3) 输出格式变化解析不了时同样降级，且原始 stdout 保留在可展开日志里不静默吞掉（[[E-39]]、[[E-90]]）
4) 配置文件缺失或语法损坏时视为「无配置值」不崩溃，提示解析失败并给出文件绝对路径（[[E-43]]）
5) 每次打开设置页按文件 mtime 重读，不长期缓存（[[E-44]]）

## 必须处理的边界

- [[E-38]]　列模型命令超时或失败
    - 触发：`grok models` / `pi --list-models` / codex app-server `model/list` 超过注册表 `modelsLive.timeoutMs`（出厂默认 5 秒，codex 出厂 10 秒，按家可覆盖）或退出码非 0
    - 期望：清单降级为「配置文件当前值 + 内置别名 + 该 agent 历史用过的模型 + 手填」，`isComplete:false`、`liveFailure` 说明原因，UI 标注「清单可能不全」，绝不阻塞派发（决策 120）
- [[E-39]]　列模型输出格式变化
    - 触发：厂商改了输出格式，解析不了
    - 期望：同 E-38 降级，且把原始 stdout 保留在可展开日志里，不静默吞掉
- [[E-43]]　配置文件缺失或损坏
    - 触发：TOML/JSON 语法错误，或文件不存在
    - 期望：视为「无配置值」，不崩溃；UI 提示解析失败并给出文件绝对路径
- [[E-44]]　用户在别处切换了模型
    - 触发：外部修改了 agent 配置文件后回到设置页
    - 期望：每次打开设置页按文件 mtime 重读，不长期缓存
- [[E-90]]　模型解析器失效
    - 触发：某家改了 models.json 结构
    - 期望：模型选择器降级为手动输入，同时保留上次成功解析的缓存清单，绝不因此禁止派发

## 实施沉淀

<!-- notes:begin -->
- **宿主和文件系统边界**：四个 reader 接收 `hostInputs` 宿主快照及可替换的 `ModelReaderFileSystem`，默认文件操作使用 `node:fs/promises`。源码契约测试禁止 adapter 直接读取 `node:os` 或使用同步文件系统 API。
- **配置错误归属**：TOML 字符串必须带引号，非法裸值会触发 `SyntaxError`；Pi 分别读取三个 JSON 文件，并通过 `configErrors` 保留每个损坏文件的绝对路径。`configError` 指向第一项，供只展示单个错误的消费者兼容使用（E-43）。
- **列模型进程生命周期**：Grok 和 Pi 的命令先经平台可执行文件解析；Windows 批处理目标再由 `wrapForComSpec` 生成完整 argv。超时不超过 5000ms，runner 必须响应 `AbortSignal`，并在子进程及输出流收敛后才返回，避免设置页关闭后遗留后台命令（E-38）。
- **Pi 空目录与降级**：`{ "providers": {} }`、`{ "models": [] }`、空数组和空对象表示已安装但尚未配置，不属于解析器失效；reader 仍合并当前配置、存储目录、历史模型和上次成功缓存。未知的非空结构标记 `isPartial` 并保留缓存（E-90）。
- **mtime 读取**：reader 每次调用都异步查询并读取当前文件，不保留跨调用的配置内容缓存，外部修改会在下一次设置页读取时生效（E-44）。
<!-- notes:end -->
