# M9-T9　多流甲板与密度档

- 所属模块：[[M9]]　**客户端界面**——两端共用的那一套界面本身：多流监看、会话查看、审批与闸门、设置与配对、落地清单，以及同一套代码的窄屏降级。它只通过 M2 的契约与 daemon 通信，**界面里不含任何业务判定**
- 前置依赖：[[M9-T7]]
- 完成后解锁：[[M9-T11]]、[[M9-T12]]、[[M9-T16]]、[[M9-T17]]

## 输入 / 产出

- **输入**：M9-T7；11 节断点表
- **产出**：`stream-column.tsx`、`useDensityTier()`

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 档位是**单点计算**的枚举（`full/compact/narrow/phone/phone-xs`）并以 prop 下传，不散落多处（[[E-235]]）
2) 流数 ≥4 默认紧凑档，用 auto-fill **换行网格**（每格 min 260px）**而非横向滚动**（[[E-164]]）
3) 紧凑档展开某条时该条占满宽度、其余保持 260px **留在同屏绝不折叠消失**（[[E-165]]）
4) 260px 放不下时加宽列宽，**不许砍掉停止控件或把状态降级成纯色点**（[[E-166]]）
5) 停止控件与审批槽位渲染在**所有档位分支之外**
配按档位枚举逐档断言停止控件存在的单测（[[E-236]]、[[E-106]]）
6) narrow 档停止键仍常驻可见，**禁止 hover 显示或收进 `⋯`**（[[E-237]]）
7) 拖动窗口切换档位时不重挂虚拟列表、不弹回顶部、不中断跟随（[[E-238]]）
8) 档位只依据视口宽度 + 指针类型，**绝不按 UA 猜设备**（[[E-239]]）
9) 流数 ≤3 且窗口 ≥1440px 时默认完整档、不出现横向滚动，档位选择记忆到本地（[[E-163]]） 10) 完整档横向滚动时若视野外某条流转成「要你」，视口左右边缘出现常驻计数标记（[[E-167]]） 11) 桌面窗口 <1100px 退化为单列列表，**不套用手机端规则**，也不允许在 900px 硬塞三栏（[[E-168]]）

## 必须处理的边界

- [[E-106]]　桌面端多流并置
    - 触发：同时 5 个以上运行流
    - 期望：多流并置（分栏或网格），每流各自带常驻停止控件；不做「一次只能看一个」的模态
- [[E-163]]　少量运行流
    - 触发：流数 ≤ 3 且窗口 ≥ 1440px
    - 期望：默认完整档、不出现横向滚动；紧凑档开关仍在，档位状态记忆到本地
- [[E-164]]　多运行流排布
    - 触发：流数 ≥ 4
    - 期望：默认紧凑档；紧凑档用 auto-fill **换行网格**（每格 min 260px）而非横向滚动，八条流在 1440px 下折成两行全部可见
- [[E-165]]　紧凑档展开某条流
    - 触发：用户点开一条细看
    - 期望：该条占满宽度、其余保持 260px 留在同屏，**绝不把其余流折叠消失**——E-106 要求每条流常驻停止控件，看不见的流等于停不掉
- [[E-166]]　紧凑档宽度不够
    - 触发：260px 放不下「头部 + 运行轨 + 停止键 + 最后一行」
    - 期望：加宽紧凑档列宽，不许砍掉停止控件或把状态降级成纯色点（那会违反 E-110）
- [[E-167]]　视野外的流转成「要你」
    - 触发：完整档横向滚动时，屏幕外某条流进入待审批态
    - 期望：视口左右边缘出现常驻计数标记（如「← 2 条待处理」），否则横向滚动恰好藏住用户唯一明确要求被提醒的那件事
- [[E-168]]　桌面窗口被拖窄
    - 触发：宽度 < 1100px
    - 期望：退化为单列列表；不套用手机端规则，也不允许在 900px 硬塞三栏
- [[E-235]]　档位分支散落各处
    - 触发：多个组件各自判断断点
    - 期望：档位必须是 `useDensityTier()` **单点计算**出的枚举（`full / compact / narrow / phone / phone-xs`）并以 prop 下传
- [[E-236]]　某一档漏掉停止键
    - 触发：档位分支影响了控件存在性
    - 期望：停止控件与审批槽位**必须渲染在所有档位分支之外**；分支只允许影响布局与截断。**配一条按档位枚举逐档断言停止控件存在的单测，把 E-106 变成机检**
- [[E-237]]　窄窗下想省空间
    - 触发：narrow 档（桌面窄窗，有鼠标）
    - 期望：停止键**仍须常驻可见**，禁止改成 hover 显示或收进 `⋯`（11 节禁令 10）
- [[E-238]]　拖动窗口打断状态
    - 触发：从 1200px 拖到 1000px 再拖回，期间某条流展开
    - 期望：档位切换**不得重挂虚拟列表把滚动位置弹回顶部**，也不得中断 SSE 跟随状态
- [[E-239]]　按 UA 猜设备
    - 触发：触屏笔电 / 平板横竖屏切换
    - 期望：档位判定**只依据视口宽度 + 指针类型，绝不按 UA 猜设备**；触屏下仍走 narrow，只把命中区放大到 44px
