# M1-T7　三平台子进程 spawn 基座与行读取器

- 所属模块：[[M1]]　**运行底座**——让 daemon 在这台机器上稳定跑起来并把字节落到磁盘上：进程单实例与端口、启动自检、开机自启注册、数据目录、结构化存储的连接与迁移、日志正文的追加写与字节偏移索引、以及全部平台差异（进程树终止、路径规范化与长路径、配置目录、子进程编码）的唯一收口。凡与操作系统、磁盘、进程存活打交道而不带任何业务概念的都归它
- 前置依赖：[[M1-T3]]、[[M1-T9]]
- 完成后解锁：[[M1-T8]]、[[M4-T3]]、[[M5-T1]]

## 输入 / 产出

- **输入**：M1-T3 的路径解析；M1-T9 的进程终止契约
- **产出**：`src/proc/`：`spawnManaged` / `line-reader` / `env` / `timers` / `registry`

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 调用方传原始参数数组且恒 `shell:false`，业务层不得拼命令串（[[E-42]]）
2) Windows `.cmd`/`.bat` 将完整参数交 M1-T3 适配器生成冻结的 ComSpec 启动对象，`proc` 原样消费其 args 与 Windows spawn 选项，不追加或二次转义
macOS/Linux 对已校验目标直接 spawn，并为托管运行建立独立进程组（[[E-119]]、[[E-130]]）
3) 行读取器在 Buffer 上只按 `0x0A` 切、剥尾部 `\r`、再 UTF-8 解码
**含 `U+2028` 的输出必须不被断行**，配回归用例（[[E-131]]、[[E-203]]）
4) 单行超 1 MiB 截断并附 `{truncated,rawByteLen}` 后继续找下一个 `\n`（[[E-141]]）
5) 非 JSON 行归入 `raw.log` 并继续，绝不中断流（[[E-140]]）
6) 子进程环境禁用 git 凭据五项且强制 UTF-8
最小环境不读取 shell 启动文件（[[E-138]]、[[E-270]]）

## 必须处理的边界

- [[E-119]]　三平台进程树残留
    - 触发：agent 派生了 node/git/npm 子进程
    - 期望：中止必须杀整棵进程树：Windows 先 `taskkill /T` 后按需 `/F`；macOS/Linux 对独立进程组先发 `SIGTERM`、3 秒后按需 `SIGKILL`。只杀父进程会留下占文件锁的孤儿进程
- [[E-130]]　agent 入口不是原生二进制
    - 触发：Windows npm 全局安装的是 `.cmd` / `.bat` 包装；macOS/Linux 入口可能是无扩展名文件或符号链接
    - 期望：注册表存平台解析后的真实绝对路径；Windows 包装脚本只经 `ComSpec`，POSIX 目标解析链接并校验普通文件和执行位后直接 spawn，不得假定 `.exe` 后缀
- [[E-131]]　编码与换行错乱
    - 触发：NDJSON 流带 CRLF、控制台代码页非 UTF-8
    - 期望：解析按行剥 `\r`，spawn 时强制 UTF-8 环境，否则中文提示词与输出乱码
- [[E-138]]　高档位下 agent 自行推远端
    - 触发：agent 想 `git push`
    - 期望：运行环境不注入任何 git 凭据、不启用 credential helper，使远端操作在凭据层失败；落地闸门恒为人工不能只靠权限档位保证
- [[E-140]]　流里混入非 JSON 行
    - 触发：agent 输出启动 banner、warning、进度条
    - 期望：逐行 try/parse，解析失败的行归入原始日志并继续，绝不中断流或丢弃该行
- [[E-141]]　单行超长撑爆缓冲
    - 触发：子进程写出 >1MB 的一条 NDJSON
    - 期望：行读取器设上限，超限时截断并标记，不因缓冲区无限增长把 daemon 拖爆
- [[E-203]]　pi 的 RPC 行读取
    - 触发：输出中出现 `U+2028` / `U+2029`
    - 期望：**必须自写只按 `\n` 切的读取器，禁用 Node `readline`**——那两个字符在 JSON 字符串里合法但会被 readline 断行；须配一条含 `U+2028` 输出的回归用例
- [[E-270]]　图形界面或自启进程找不到 shell 中已安装的 agent
    - 触发：agent 只通过 `.zshrc`、`.bashrc` 等 shell 启动文件加入 `PATH`，而 macOS/Linux GUI 或服务没有继承这些变量
    - 期望：先使用用户配置的绝对路径，再检查平台级固定候选目录；仍找不到时列出已检查位置并要求用户选择文件，不读取、不执行用户 shell 启动文件
- [[E-42]]　模型名含 shell 元字符
    - 触发：模型名带空格、引号或 `;` `&` 之类
    - 期望：调用方传原始参数数组，业务层不拼命令串；原生程序直接传 argv，Windows 包装脚本仅由适配器按 08 节组装完整 ComSpec 命令，最终参数值与个数必须不变且不得执行额外命令
