# M1-T7　子进程 spawn 基座与行读取器

- 所属模块：[[M1]]　**运行底座**——让 daemon 在这台机器上稳定跑起来并把字节落到磁盘上：进程单实例与端口、启动自检、开机自启注册、数据目录、结构化存储的连接与迁移、日志正文的追加写与字节偏移索引、以及全部平台差异（进程树终止、路径规范化与长路径、配置目录、子进程编码）的唯一收口。凡与操作系统、磁盘、进程存活打交道而不带任何业务概念的都归它
- 前置依赖：[[M1-T3]]
- 完成后解锁：[[M1-T8]]、[[M4-T3]]、[[M5-T1]]

## 输入 / 产出

- **输入**：M1-T3 的 platform
- **产出**：`src/proc/`：`spawnManaged` / `line-reader` / `env` / `timers` / `registry`

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 恒 `shell:false` + 参数数组，全仓无拼 shell 字符串（[[E-42]]）
2) `.cmd`/`.bat` 走 `comSpec` + `['/d','/s','/c',...]` 且仍是数组（[[E-130]]）
3) 行读取器在 Buffer 上只按 `0x0A` 切、剥尾部 `\r`、再 UTF-8 解码
**含 `U+2028` 的输出必须不被断行**，配回归用例（[[E-131]]、[[E-203]]）
4) 单行超 1 MiB 截断并附 `{truncated,rawByteLen}` 后继续找下一个 `\n`（[[E-141]]）
5) 非 JSON 行归入 `raw.log` 并继续，绝不中断流（[[E-140]]）
6) 子进程环境禁用 git 凭据五项且强制 UTF-8（[[E-138]]）

## 必须处理的边界

- [[E-130]]　agent 不是 .exe
    - 触发：npm 全局安装的 `.cmd` / `.ps1` 包装
    - 期望：注册表存实际可执行路径并按需 shell 包装，不得假定后缀
- [[E-131]]　编码与换行错乱
    - 触发：NDJSON 流带 CRLF、控制台代码页非 UTF-8
    - 期望：解析按行剥 `\r`，spawn 时强制 UTF-8 环境，否则中文提示词与输出乱码
- [[E-138]]　高档位下 agent 自行推远端
    - 触发：agent 想 `git push`
    - 期望：运行环境不注入任何 git 凭据、不启用 credential helper，使远端操作在凭据层失败；落地闸门恒为人工不能只靠权限档位保证
- [[E-140]]　流里混入非 JSON 行
    - 触发：agent 输出启动 banner、warning、进度条
    - 期望：逐行 try/parse，解析失败的行归入原始日志并继续，绝不中断流或丢弃该行
- [[E-141]]　单行超长撑爆缓冲
    - 触发：子进程写出 >1MB 的一条 NDJSON
    - 期望：行读取器设上限，超限时截断并标记，不因缓冲区无限增长把 daemon 拖爆
- [[E-203]]　pi 的 RPC 行读取
    - 触发：输出中出现 `U+2028` / `U+2029`
    - 期望：**必须自写只按 `\n` 切的读取器，禁用 Node `readline`**——那两个字符在 JSON 字符串里合法但会被 readline 断行；须配一条含 `U+2028` 输出的回归用例
- [[E-42]]　模型名含 shell 元字符
    - 触发：模型名带空格、引号或 `;` `&` 之类
    - 期望：参数以数组形式传给子进程，任何情况下不拼接 shell 字符串
