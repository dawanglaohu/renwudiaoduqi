# M9-T13　手机原样重跑入口

- 所属模块：[[M9]]　**客户端界面**——两端共用的那一套界面本身：多流监看、会话查看、审批与闸门、设置与配对、落地清单，以及同一套代码的窄屏降级。它只通过 M2 的契约与 daemon 通信，**界面里不含任何业务判定**
- 前置依赖：[[M9-T12]]、[[M8-T5]]
- 完成后解锁：无，它不卡别人

## 输入 / 产出

- **输入**：M8-T5 的重跑接口
- **产出**：流详情页末尾的整宽按钮

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 仅对终态失败/已中止的运行可用，严格复用原派发载荷、**不出现任何选择器**，需一次确认（[[E-177]]）
2) 入口在流详情页日志末尾的整宽按钮，**不进拇指条**
拇指区仍只有停止与审批
3) 「换 agent／换模型重派」保持桌面端独占，手机上只显示一行「请到桌面端」，不做半截表单
4) 手机端不提供「全部重跑」（[[E-181]]）
5) 竖屏 <400px 时该按钮整宽独占一行，与拇指条保持间距防误触

## 必须处理的边界

- [[E-177]]　手机重跑撞上已在跑
    - 触发：该任务已从桌面端重派或已重新在跑
    - 期望：按钮置灰 + 幂等键拦截，绝不产生第二次运行
- [[E-181]]　早上多条失败
    - 触发：一夜之间多个任务挂掉
    - 期望：逐条进入、逐条确认；手机端**不提供「全部重跑」**，批量属编排，留在桌面端
