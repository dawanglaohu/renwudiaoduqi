- 完成后解锁：[[M9-T8]]、[[M9-T9]]、[[M9-T10]]、[[M9-T21]]

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 运行轨**贯穿整栏全高**含未来步骤的虚线段
只画到当前步即判不合格
2) 六种轨段形态（实线／心跳点／虚线／空心方块＋整段转暖／平头截断／半调虚线＋横杠）各自可见且形状先于颜色
3) 条目折叠高度 30px（触摸 44px），网格 `20px minmax(0,1fr) auto 16px`
**每一步都显示耗时**
4) 标签为「工具 + 对象」，成功步默认折叠、失败步默认展开并提供「从这一步重试」
5) 键盘焦点用**内嵌环**，滚动列表不整体抖
6) 轨段形态与状态徽标共用同一张形状枚举，状态区分不只靠色相（[[E-110]]）
「失联」「审查未完成」等态各有专属形状而非复用失败形状（[[E-230]]）

## 必须处理的边界

- [[E-110]]　长时间盯屏与色觉差异
    - 触发：用户连续监看数小时，或投屏/色弱
    - 期望：深色为默认，日志用等宽字体；状态区分不能只靠色相，必须同时有形状或文字
- [[E-230]]　有状态没有专属字形
    - 触发：「失联」「审查未完成」「未识别/降级」这些态不等同于「失败」
    - 期望：形状枚举必须为它们**各补一个专属形状**，绝不复用 `✕`，更不允许只靠颜色区分

## 实施沉淀

<!-- notes:begin -->
1. 轨贯穿全高的几何机制：否决了使用 JavaScript 动态计算行高或 ResizeObserver 绝对定位轨线的方案（违反 07 节架构禁令「轨不测量 DOM」），采用纯 CSS flexbox 与 SVG viewBox 方案。每个 stream-row 的第一列（20px）利用相对定位与固定的中心线 x=11px 首尾自然连通；同时在 Spine 根容器末尾渲染 flex-1 填满剩余高度的未来虚线段，在不测量 DOM 的前提下确保任意列表长度下轨线均能贯穿整栏全高。
2. 展开区 2px 延续轨：当条目展开时，在展开容器左缘设置绝对定位线段（`left: 11px; transform: translateX(-50%); width: 2px; top: 0; bottom: 0`），覆盖展开区域全部高度，并根据当前轨段形态连接相应颜色（如 failed 接 `--spine-dead`、waiting 接 `--spine-needs` 等），避免展开时整轨中断。
3. 当前步心跳环与 1.6s 呼吸动画：当前步必须渲染心跳环（--spine-live / --auto）且明确消费 tokens.css 的 `--pulse: 1.6s`。步骤类型专属字形（如 tool ⬡, file_write ▤ 等）内嵌于外层呼吸环中，两者共存，步骤字形不得吞掉呼吸环。
4. 形状先于色相与专属字形（E-110, E-230）：轨段节点复用 M9-T2 的 `spine-shape.ts` 形状字典。对于「等你（waiting）」状态，优先将当前点渲染为 9px 空心方块并将后续轨段转换为 `--spine-needs` 暖色；但当指定具体状态为 `orphaned`（失联）、`review_incomplete`（审查未完成）或 `unrecognized`（未识别）时，优先保留各状态在 16x16 视口下的专属几何轮廓（双环链扣、未决放大镜、问号虚线圆），杜绝退化为对角叉号 ✕ 或仅靠颜色区分。失败步错误横幅同样通过 `StatusIcon(state="failed")` 渲染内联 SVG path，禁止裸字符 ✕。
5. 失败平头截断与停止横杠：失败状态下移除向下延续的竖线并在节点下方 6px 处绘制宽度为 4px 的平头横向端帽（`x1=9, x2=13, strokeWidth=2`），视觉明确传达「断了不再走」；已停止状态下采用半调虚线并在端点绘制 10px 宽度横杠（`x1=6, x2=16`），视觉明确传达「主动停止非崩溃」。
6. 耗时展示与无抖动焦点：耗时严格使用等宽数字（Public Sans 标签 + Commit Mono 耗时）。无耗时数据（null/undefined/0/负数）必须返回 `'—'`，杜绝返回 `'0'` 或 `'0ms'` 误导用户。键盘交互通过 `tabIndex={0}` 配合 `shadow-[inset_0_0_0_2px_var(--needs)]` 内嵌环，不增加外部盒模型尺寸，彻底避免滚动列表在焦点切换时产生整体抖动。
