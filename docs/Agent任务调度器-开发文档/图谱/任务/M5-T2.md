# M5-T2　base 选择与上游产出校验

- 所属模块：[[M5]]　**工作区与 Git**——为每个任务准备、隔离与回收独立 worktree，从中读出改动（改动文件数、diff stat、diff 正文）并生成只读落地清单。凡要碰 git 或任务工作目录的都归它

- 完成后解锁：[[M8-T3]]

## 输入 / 产出

- **输入**：M5-T1；任务依赖图
- **产出**：base 解析逻辑

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 上游任务改动尚未落地进当前 HEAD 就要派下游时**拒绝派发**并说明「下游 base 缺上游产出」（[[E-70]]）
2) 同时提供「以上游任务分支为 base 建 worktree」的显式选项，**绝不默默从旧 HEAD 起**（[[E-70]]）
3) 每任务独立 session 与独立工作区，每 agent 有并发上限（[[E-31]]）

## 必须处理的边界

- [[E-31]]　同一 agent 并发多任务
    - 触发：一个 agent 被同时派多个任务
    - 期望：每任务独立 session 与独立工作区（grok 用自带 --worktree，其余用 git worktree 兜底），并设每 agent 并发上限
- [[E-70]]　下游 base 缺上游产出
    - 触发：上游任务改动尚未被用户落地进当前 HEAD 就要派下游
    - 期望：拒绝派发并说明「下游 base 缺上游产出」，同时提供「以上游任务分支为 base 建 worktree」的显式选项；绝不默默从旧 HEAD 起
