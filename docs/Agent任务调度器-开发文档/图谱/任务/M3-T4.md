# M3-T4　文档接管横幅与阅读器入口

- 所属模块：[[M3]]　**文档接入**——把 `docs-data.js` 变成本产品唯一的任务真相源（任务、依赖、批次、并行窗口、验收标准、边界编号、实施与审查两段提示词），并负责内容指纹、派发时快照与文档重出后的三个标记。凡「这条数据来自文档」的都归它
- 前置依赖：[[M3-T2]]
- 完成后解锁：无，它不卡别人

## 输入 / 产出

- **输入**：M3-T2
- **产出**：`system.docs_changed` 事件、接管横幅数据、`http/routes/documents.ts`（含 `open-reader` 与 `settings` 两个端点）

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 首次接管某文档时给一次性横幅「本文档任务状态已由调度器接管，阅读器里的手工三态不再有效」，可关闭并按文档记住（[[E-84]]）
2) 调度器**永不读也永不写**阅读器的 localStorage（[[E-83]]）
3) 「打开原文档阅读器」以系统默认浏览器打开原 `index.html`，不注入脚本、不改磁盘任何文件（[[E-85]]）
4) 文档目录被移动或重命名时提示「文档路径不可用，请重新定位」，任务记录、快照、会话指针全部保留（[[E-86]]）
5) 调度器**不读不写任何浏览器存储**
阅读器里手点三态与手调窗口数都不影响调度器（[[E-249]]）

## 必须处理的边界

- [[E-249]]　阅读器与调度器同时开着
    - 触发：`file://` 阅读器与调度器并行运行
    - 期望：调度器**不读不写任何浏览器存储**；阅读器里手点三态不影响调度器的窗口数与进度
- [[E-83]]　用户仍去点交接台的手工三态
    - 触发：双击打开 file:// 阅读器并点了状态
    - 期望：调度器永不读也永不写那份 localStorage；任务卡上不显示、不同步交接台状态
- [[E-84]]　首次接管某文档
    - 触发：调度器第一次导入这份文档
    - 期望：顶部一次性横幅「本文档任务状态已由调度器接管，阅读器里的手工三态不再有效」，可关闭并按文档记住
- [[E-85]]　打开原文档阅读器
    - 触发：用户点「打开原阅读器」入口
    - 期望：以系统默认浏览器打开原 index.html，原样打开，不注入脚本、不改磁盘上任何文件
- [[E-86]]　文档目录被移动或重命名
    - 触发：入口链接失效
    - 期望：提示「文档路径不可用，请重新定位」；已有任务记录、快照、会话指针全部保留
