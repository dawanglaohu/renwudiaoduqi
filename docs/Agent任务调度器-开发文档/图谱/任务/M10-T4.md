# M10-T4　两端版本校验与打包管线

- 所属模块：[[M10]]　**桌面壳与手机壳**——只做窗口与单实例、系统通知、令牌安全存储三件事的两个原生容器，外加 daemon 未运行时的引导与运行时缺失检测。壳按界面声明的可选桥接接口去实现，界面在没有壳时按能力探测降级，因此依赖方向恒为壳→界面
- 前置依赖：[[M10-T2]]、[[M10-T3]]
- 完成后解锁：无，它不卡别人

## 输入 / 产出

- **输入**：两个壳
- **产出**：`GET /version` 校验接线、打包脚本

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 壳启动时校验 `apiVersion`，不兼容时提示升级**而不是抛底层错误**（[[E-14]]）
2) daemon 的 `@fastify/static`、Tauri 的 `frontendDist`、Capacitor 的 `webDir` **三处消费同一次构建**，产物内容一致
3) `base: './'` 相对路径在三种加载源下均可加载，无 404
4) 字体随产物托管，**不引入任何 CDN 或外链**（[[E-175]]）
5) 字体加载失败时回退 `ui-monospace` 且布局不塌，列宽用 `ch` 计算（[[E-174]]）
6) 只自托管实际用到的字重（[[E-176]]）

## 必须处理的边界

- [[E-14]]　两端版本不一致
    - 触发：只更新了桌面壳或只更新了手机壳
    - 期望：daemon 暴露 API 版本号，壳启动时校验，不兼容时提示升级，而不是抛底层错误
- [[E-174]]　字体加载失败
    - 触发：woff2 打包遗漏或加载失败
    - 期望：回退到 `ui-monospace` 系统栈且布局不得塌——列宽用 `ch` 计算，禁止依赖具体字体度量的写死像素宽
- [[E-175]]　无外网环境
    - 触发：手机壳冷启动、局域网 daemon 可达但无公网
    - 期望：字体与 Web UI 同源同命运，随 daemon 静态产物一起托管，**不单独引入 CDN**
- [[E-176]]　字体体积
    - 触发：打包字重范围
    - 期望：只自托管实际用到的字重（常规 + 一个强调档），不打包全家族
