# M10-T4　两端版本校验与共享打包管线

- 所属模块：[[M10]]　**桌面壳与手机壳**——只做窗口与单实例、系统通知、令牌安全存储三件事的两个原生容器，外加 daemon 未运行时的引导、Windows/macOS/Linux 桌面构建与运行依赖检测。壳按界面声明的可选桥接接口去实现，界面在没有壳时按能力探测降级，因此依赖方向恒为壳→界面
- 前置依赖：[[M10-T2]]、[[M10-T3]]
- 完成后解锁：[[M10-T5]]

## 输入 / 产出

- **输入**：两个壳；10 节 `/api/v1/version` 端点表与 `VersionResponse`
- **产出**：daemon 侧暴露 `GET /api/v1/version`（`{daemon, apiVersion, node}`）、两个壳启动期消费同一次构建前的版本校验接线、共享打包脚本（daemon 静态托管 / Tauri `frontendDist` / Capacitor `webDir` 指向同一份 `packages/web/dist`，字体二进制随该产物自托管，web 具备可构建入口）

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 壳启动时校验 `apiVersion`，不兼容时提示升级**而不是抛底层错误**（[[E-14]]）
2) daemon 的 `@fastify/static`、三平台 Tauri 的 `frontendDist`、Capacitor 的 `webDir` **全部消费同一次构建**，产物内容一致
3) `base: './'` 相对路径在各加载源下均可加载，无 404
4) 字体随产物托管，**不引入任何 CDN 或外链**（[[E-175]]）
5) 字体加载失败时回退 `ui-monospace` 且布局不塌，列宽用 `ch` 计算（[[E-174]]）
6) 只自托管实际用到的字重（[[E-176]]）

## 必须处理的边界

- [[E-14]]　两端版本不一致
    - 触发：只更新了桌面壳或只更新了手机壳
    - 期望：daemon 暴露 API 版本号，壳启动时校验，不兼容时提示升级，而不是抛底层错误
- [[E-174]]　字体加载失败
    - 触发：woff2 打包遗漏或加载失败
    - 期望：回退到 `ui-monospace` 系统栈且布局不得塌——列宽用 `ch` 计算，禁止依赖具体字体度量的写死像素宽
- [[E-175]]　无外网环境
    - 触发：手机壳冷启动、局域网 daemon 可达但无公网
    - 期望：字体与 Web UI 同源同命运，随 daemon 静态产物一起托管，**不单独引入 CDN**
- [[E-176]]　字体体积
    - 触发：打包字重范围
    - 期望：只自托管实际用到的字重（常规 + 一个强调档），不打包全家族

## 实施沉淀

<!-- notes:begin -->
1. **API 版本只在一处声明。** `CURRENT_API_VERSION` 与 `VersionResponse` 只从 `packages/shared/src/api/system.ts` 导出。daemon 的 `/api/v1/version`、两个壳的期望版本都读这一份。壳里再写 `'v1'` 或内联 `{apiVersion, daemon, node}` 会在破坏性升级时漏改一端。
2. **hostHint 取不到就当服务未启动，禁止猜 127.0.0.1。** 手机壳上 loopback 是手机自己，不是电脑上的 daemon。缺地址走 E-146/E-04 的连接引导，不发起版本请求，也不进重连循环。
3. **静态托管缺 dist 必须启动失败。** `80-static.ts` 只认源码布局 `plugins/ -> packages/web/dist` 和安装包布局 `daemon 根 -> web/dist`，禁止相对 cwd 回退。dist 不存在就抛错退出，否则 `/index.html` 会静默 404，壳看起来像连不上。
4. **机检对着产物，不对着源码注释。** 单构建检查必须读 daemon 的 `80-static.ts` 与真实 `packages/web/dist`；字体检查必须让 dist/fonts 的 woff2 集合等于 fonts.css 声明；CSS 里出现 `url(/…)` 即失败。挪走一个 woff2、把 base 改成 `/`、把 daemon root 指到别处，三条负例各自必须 FAIL。
5. **字体 URL 用 `/fonts/…` 源路径，靠 `base: './'` 变成相对产物路径。** 源里写成 `./fonts/…` 时 Vite 会按 CSS 所在目录解析，public/fonts 对不上，构建后 URL 原样留下且 dist/fonts 可能空。`base: './'` 会把 `/fonts/x.woff2` 写成 `../fonts/x.woff2`，三处宿主都能加载。
6. **「文件在就算自托管」是假通过。** 六个 288 字节的 wOF2 占位桩（totalSfntSize≈620、Brotli 流解不出 sfnt、零字形）能骗过「声明集合 === 文件集合」的检查，运行期却只会静默回退——字面要求满足了，字体的作用没有。机检因此加硬到读 woff2 头部（签名、声明长度、sfnt 字节下限），并把审查方换上的真实 SIL OFL 拉丁子集（Public Sans/Commit Mono 400/500/600）作为基准。
7. **E-146 与 E-14 是两件事，别用同一个状态表示。** daemon 未运行（`unreachable`）必须留在连接失败页给「启动 daemon」按钮；只有可达但版本不符或版本接口不可用时才切 `incompatible` 显示升级页。把两者都切成 `incompatible`，用户会被告知去升级一个根本没启动的服务。
