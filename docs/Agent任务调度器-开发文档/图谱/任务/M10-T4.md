# M10-T4　两端版本校验与共享打包管线

- 所属模块：[[M10]]　**桌面壳与手机壳**——只做窗口与单实例、系统通知、令牌安全存储三件事的两个原生容器，外加 daemon 未运行时的引导、Windows/macOS/Linux 桌面构建与运行依赖检测。壳按界面声明的可选桥接接口去实现，界面在没有壳时按能力探测降级，因此依赖方向恒为壳→界面
- 前置依赖：[[M10-T2]]、[[M10-T3]]
- 完成后解锁：[[M10-T5]]

## 输入 / 产出

- **输入**：两个壳
- **产出**：`GET /version` 校验接线、打包脚本

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 壳启动时校验 `apiVersion`，不兼容时提示升级**而不是抛底层错误**（[[E-14]]）
2) daemon 的 `@fastify/static`、三平台 Tauri 的 `frontendDist`、Capacitor 的 `webDir` **全部消费同一次构建**，产物内容一致
3) `base: './'` 相对路径在各加载源下均可加载，无 404
4) 字体随产物托管，**不引入任何 CDN 或外链**（[[E-175]]）
5) 字体加载失败时回退 `ui-monospace` 且布局不塌，列宽用 `ch` 计算（[[E-174]]）
6) 只自托管实际用到的字重（[[E-176]]）

## 必须处理的边界

- [[E-14]]　两端版本不一致
    - 触发：只更新了桌面壳或只更新了手机壳
    - 期望：daemon 暴露 API 版本号，壳启动时校验，不兼容时提示升级，而不是抛底层错误
- [[E-174]]　字体加载失败
    - 触发：woff2 打包遗漏或加载失败
    - 期望：回退到 `ui-monospace` 系统栈且布局不得塌——列宽用 `ch` 计算，禁止依赖具体字体度量的写死像素宽
- [[E-175]]　无外网环境
    - 触发：手机壳冷启动、局域网 daemon 可达但无公网
    - 期望：字体与 Web UI 同源同命运，随 daemon 静态产物一起托管，**不单独引入 CDN**
- [[E-176]]　字体体积
    - 触发：打包字重范围
    - 期望：只自托管实际用到的字重（常规 + 一个强调档），不打包全家族

## 实施沉淀

<!-- notes:begin -->
1. **统一单构建消费与各宿主相对路径契约（AC 2、AC 3）**：Tauri `frontendDist`、Capacitor `webDir` 与 daemon 静态托管均统一指向 `packages/web/dist`，禁止为不同平台生成多套产物。`vite.config.ts` 必须严格配置 `base: './'`，因为在原生桌面容器（`tauri://localhost`）与手机容器（`https://localhost`）中，绝对路径（如 `/assets/...`）会脱离应用根上下文直接触发 404，导致脚本与样式无法加载；只有相对路径能在本地文件、自定义原生协议与 HTTP 宿主下一致解析。
2. **两端版本校验与非致命升级引导（AC 1、E-14）**：双壳启动连接 daemon 时，主动调用 `GET /api/v1/version` 比对 `apiVersion`。两端版本不一致时，严禁抛出底层网络异常、未捕获 Promise 拒绝或进入无限重连循环，而是由桌面连接控制器转换至 `incompatible` 状态并渲染带设计 token 的升级提示页，移动端返回结构化 `MobileUpgradeNotice`，明确指示用户更新桌面应用或调度服务；网络不可达与版本格式损坏同样静默兜底为非致命状态。
3. **字体零 CDN 托管与度量降级防塌陷（AC 4、AC 5、AC 6，E-174、E-175、E-176）**：全离线与局域网冷启动场景下禁止依赖任何外网 CDN。`fonts.css` 仅声明自托管的常规（400）与强调（600）拉丁子集字重，拒绝全字族打包；`--font-mono` 强制将 `ui-monospace` 置于系统栈前列。所有等宽数据列宽一律使用 `ch` 单位计算（如 `calc(N * 1ch)`），禁止硬编码像素宽度，防止 woff2 缺失或系统回退字体在字符度量差异下破坏排版。
4. **共享打包管线机检闭环**：通过双端各自的 `package-pipeline.ts` 校验器，在 CI 与本地构建前置断言单构建目录对齐、相对 base 声明、零 CDN 引用、字体回退栈与字重预算五项硬指标，任一违规直接阻断打包流程，避免错误的构建配置渗透至原生安装包。
<!-- notes:end -->
