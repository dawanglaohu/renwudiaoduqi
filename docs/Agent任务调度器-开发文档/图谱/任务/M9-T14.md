## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 每个字段显示「内置默认 / 你的覆盖 / 当前生效」三行并带「恢复默认」（[[E-92]] 的呈现侧）
2) 模型下拉与桌面共用同一份清单数据，手机端退化为全屏选择器，**不因屏宽裁剪候选项**
3) 清单不全时明示「清单可能不全」并保留手填入口（[[E-38]] 的呈现侧）
4) agent 不可用时置灰并写明缺什么，点击可跳到该项配置（[[E-88]] 的呈现侧）
5) 两字符短码可编辑、保存时唯一性校验，撞车要求改一个（[[E-183]]）
6) 紧凑档或窄屏下字母组必须配合完整名称出现在流头部，长按/悬停出全名，**字母组不得成为唯一标识**（[[E-184]]）
7) 接入第 5/6 个 agent 只需填两字符短码，**不新增任何资源文件**（[[E-185]]）
8) 并行窗口数是本产品自己的设置（默认 2，值域 1–6，按文档持久化），设置项旁注明「此值只属于调度器，与阅读器互不影响」（[[E-248]]）
9) 收到 `reason` 精确等于 `session-dir-overlap` 的告警时显示「会话记录可能互相覆盖」，不按 daemon 的英文开发者 message 直出中文（[[E-95]] 的呈现侧） 10) **呈现侧数据来源与落点（本次审查定点补记，不改已有 1–9 条）**：三层表的「内置默认」「你的覆盖」与顶层生效值只读 daemon 提供的字段——`AgentEntryDto.layers` 与 `PATCH /agents/:id {clearOverrides}` 由 M4-T14 落地，**在此之前 daemon 未提供的层显示「—」**
前端不得自建与 `config/defaults.ts` 平行的注册表副本（含短码／可执行路径等出厂值），也不得按 `agentId` 判「是不是某一家」的分支
「恢复默认」不得把前端算出的默认值当请求体发出（`defaultModel` 之类内置默认非字符串时更不得发）。[[E-92]] 的「内置默认已更新（旧值 → 新值）」与一键采纳只呈现 daemon 提供的升级差异，**前端不得伪造 `defaultUpdates` / `warnings` 这类 daemon 不存在的字段**。[[E-95]] 只按 `reason` 精确等于 `session-dir-overlap` 分支，该原因经 `agent.availability_changed` 事件的 `vendor.reason` 到达（`packages/daemon/src/boot/container.ts`），**不得按 daemon 的英文 message 匹配或直出**。[[E-185]] 指 agent 身份由注册表 `monogram` 文本呈现、接入新 agent 不新增任何资源文件
daemon 没有创建 agent 的路由，故本任务**不提供只改本地 state 的新增入口**。展示组件（`agent-card.tsx` / `model-picker.tsx` 等）落 `packages/web/src/components/`（07 节 components 清单，M9-T23 亦按该落点增量消费），`features/settings-agents/` 只留 `use-〈域〉.ts` 与 `〈域〉-container.tsx`，容器里只许写 grid/flex/gap。

## 必须处理的边界

- [[E-183]]　字母组撞车
    - 触发：两个 agent 取到同一个两字符短码
    - 期望：短码是注册表里**用户可编辑**的字段而非自动首字母推导；保存时做唯一性校验并要求改一个
- [[E-184]]　窄处的身份识别
    - 触发：紧凑档 260px 或手机窄屏
    - 期望：字母组必须配合完整名称出现在流头部；紧凑档可只显字母组，但需长按/悬停出全名，字母组不得成为唯一标识
- [[E-185]]　接入新 agent 的视觉成本
    - 触发：用户接入第五、第六个 agent
    - 期望：只填两字符短码即可上线，不新增任何资源文件
- [[E-248]]　两边窗口数不一致
    - 触发：用户在阅读器里调过 2、调度器是别的值
    - 期望：调度器一律用自己的值，且设置项旁注明「此值只属于调度器，与阅读器互不影响」，防止用户以为改一边等于改两边
- [[E-38]]　列模型命令超时或失败
    - 触发：`grok models` / `pi --list-models` / codex app-server `model/list` 超过注册表 `modelsLive.timeoutMs`（出厂默认 5 秒，codex 出厂 10 秒，按家可覆盖）或退出码非 0
    - 期望：清单降级为「配置文件当前值 + 内置别名 + 该 agent 历史用过的模型 + 手填」，`isComplete:false`、`liveFailure` 说明原因，UI 标注「清单可能不全」，绝不阻塞派发（决策 120）
- [[E-88]]　可执行路径无效
    - 触发：配置里的路径不存在或不可执行
    - 期望：该 agent 标「不可用（路径无效）」，从派发目标下拉中移除，不阻塞其他 agent；点击可直接跳到该项配置
- [[E-92]]　升级后内置默认变了
    - 触发：用户恰好覆盖了同一字段
    - 期望：保留用户覆盖，在该字段旁提示「内置默认已更新（旧值 → 新值）」并给一键采纳
- [[E-95]]　两个 agent 配成同一路径
    - 触发：用户复制配置后没改
    - 期望：允许；会话目录若也相同，daemon 产生 `reason` 精确等于 `session-dir-overlap` 的英文告警但不拒绝保存，设置页按该原因显示「会话记录可能互相覆盖」

## 实施沉淀

<!-- notes:begin -->
1. 三层配置架构（内置默认 / 你的覆盖 / 当前生效）：字段渲染解耦为三行视图，纯读 daemon 下发的 `AgentEntryDto.layers` 字段，缺失时显示「—」，绝不在前端反推或硬编码出厂值表；「恢复默认」在 clearOverrides 接口正式落地前不暴露写入口，绝不把前端算出的值充当 PATCH 请求体（R1）。
2. 手机端全屏选择器与不裁剪原则（AC 2）：在窄视口下（<640px）传统下拉面板会挤压文本，导致带有日期后缀的模型名被截断；全屏浮层采用定高 touch target（44px）与 break-all 换行，确保全名完整可读；清单不全时（E-38）开放自定义输入，保障派发链路不被阻塞。
3. 短码防撞车与中性视觉（E-183, E-185）：短码为用户可编辑的两字符大写字母组，保存前遍历已注册 agent 进行大小写无关排他比对；agent 直接以 CSS 中性 ink chip 纯文本渲染，无需引入任何外部资源；删掉只改本地 state 的虚假新增入口（R6）。
4. 调度器并行窗口数独立性（E-248, R5）：并行窗口设置（1–6，默认 2）严格属于调度器本身，与阅读器互不影响；更新目标文档必须来自明确的上下文（localStorage 记录或快照目标），未定位到目标文档时禁用写入口，避免盲目对 documents[0] 脏写；写入失败时回滚并就地呈现 inline 错误。
5. 告警原因本地化映射与错误回滚（E-95, R3, R4, R8）：严格按 reason === 'session-dir-overlap' 分支映射输出中文安全提示，绝不按英文 message 匹配或直出英文；不可用状态按 unavailableCode 映射中文标题，英文原因/缺失项全部收纳进可展开技术详情；更新字段与窗口数失败时均触发状态回滚，并将错误依字段精准渲染至控件下方。
