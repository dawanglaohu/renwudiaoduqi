# M4-T7　三档权限与三档思考强度的抽象与厂商参数映射

- 所属模块：[[M4]]　**Agent 适配**——把形态各异的 agent 抽象成同一个可派发对象：注册表（含每个 agent 通用的版本指纹探测字段与具名的「适配器种类」枚举）、可执行探测、模型清单读取与降级、启动参数与三档权限映射、以各家原生通道为主干把输出归一化成 ACP `session/update` 词汇的事件、可回话与**是否提供流式事件**等能力位，并自实现一个通用 ACP 适配器作为兜底与第 6 家及以后的入口。凡「某一家 agent 跟别家怎么不一样」的都归它
- 前置依赖：[[M4-T1]]
- 完成后解锁：[[M7-T2]]、[[M9-T17]]

## 输入 / 产出

- **输入**：04 节实测的各家权限参数；各家思考强度参数
- **产出**：`domain/permission-tier.ts`、`domain/effort-tier.ts` 两张映射表

## 验收标准

> 逐条都要满足，这是验收时的唯一依据。

1) 注册表只存本产品三档抽象（只读／工作区可写／无限制），映射到 `--sandbox` / `--permission-mode` 的表在代码层，**用户不直填厂商参数**（[[E-137]]）
2) 默认中档
某 agent 被手动调到最高档时该卡片与每次派发确认页**持续**显示醒目标记（非一次性 toast），且档位不随切到「自动模式」而隐式变化（[[E-136]]）
3) 审查阶段派出去的 agent 固定只读档（[[E-135]]）
4) **思考强度同样只存三档抽象（低／中／高）**，到各家参数的映射（codex `model_reasoning_effort`、claude 思考预算、其余按实测填）在代码层，用户不直填厂商原值（决策 52）
5) 五家中任一不支持该能力时映射表返回「不支持」而非某个默认值，由 M4-T6 走 [[E-254]] 的空值路径
6) 自报值与所选不一致时如实上报两者，**不静默采信任何一边**（[[E-256]]）

## 必须处理的边界

- [[E-135]]　审查 agent 的权限
    - 触发：审查阶段派出去的 agent
    - 期望：固定给只读档（read-only / plan），审查 agent 不得改代码，否则「审查通过」失去意义
- [[E-136]]　某 agent 被调到最高档
    - 触发：用户手动提权
    - 期望：该 agent 卡片与每次派发确认页持续显示醒目标记（非一次性 toast）；档位不随切换到「自动模式」而隐式变化
- [[E-137]]　各家权限参数语义不一
    - 触发：codex `--sandbox` vs claude/grok `--permission-mode`
    - 期望：注册表只存本产品的三档抽象（只读 / 工作区可写 / 无限制），映射到厂商参数的表放在代码层，不让用户直填原始参数
- [[E-254]]　agent 不支持思考强度
    - 触发：dsh 无对应参数；某些模型或某些 agent 版本也没有
    - 期望：该 agent 的思考强度置 NULL、**派发时不传任何相关参数**，UI 一律显示「—」并在 title 说明原因。**绝不补一个默认档冒充**——补了等于谎称控制生效（与 E-26「数据缺失显示—，不拿 0 冒充」同理）。不因不支持而禁用该 agent（与 E-35 对称）
- [[E-256]]　自报思考强度与所选不一致
    - 触发：agent 实际用的档位与派发时所选不同
    - 期望：与 `reported_model` 对称：**流头部持续高亮标出两者**（`高 → 实际 中`），不静默采信任何一边；该运行的收据里一并记录实际值

## 实施沉淀

<!-- notes:begin -->
- `agents.json` 全链路只存 `readOnly` / `workspaceWrite` / `unrestricted` 三档抽象，默认为工作区可写；用户覆盖持久化后不会因自动模式变更。
- 厂商映射结果保留 argv、环境变量或不支持三种事实。Claude 1.0.67 的思考预算通过 `MAX_THINKING_TOKENS` 传入；DSH 的权限通过 `DSH_PERMISSION_MODE` 传入；通用 ACP 不臆造 CLI 权限参数。
- Pi 内置的 `write` 与 `edit` 工具接受绝对路径，所以不用工具白名单冒充工作区沙箱；没有外部沙箱时，Pi 的中档映射明确返回不支持。
- 思考强度支持性由适配器或模型探测结果传入；自报反向映射只认该厂商已知值，未知值保留原文并标记不一致。
<!-- notes:end -->
