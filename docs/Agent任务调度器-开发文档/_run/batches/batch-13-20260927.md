## 交付了什么

1. **浏览器主路径与人工闸门（R1）**：使用正式 daemon bootstrap 启动服务，真实 Chromium 浏览器加载正式 Web 构建产物（`packages/web/dist`）。通过向导控件完成选文档、选批次、逐任务独立指派并写入草稿；将落地闸门配置为手动；真实任务派发并流转至 `awaiting_human` 状态后，在浏览器运行甲板泳道中就地呈现 `GateCard` 审批卡，由 Playwright 真实点击「批准并继续」作出人工审批决定，验证卡片消失、闸门决议为 `pass` 且运行推进至落地。
2. **离线、补推、退避与撤销（R2）**：断网拦截下断言离线横幅包含「最后同步于」、连接状态变为离线且派发能力禁用；记录重连时间戳证实存在重试退避间隔而非 0ms 无间隔轮询；断网期间 fake-agent 产出的消息在断网期 DOM 呈现严格为 0（负向控制），恢复网络后携带 `Last-Event-ID` 重连成功，断言离线消息在 DOM 中恰好补推一次（`count === 1`，不丢不重）；服务端撤销设备令牌后验证旧流断开、旧凭据请求返回 401、浏览器清除凭据并重定向至 `#/pair` 且停止无限重连。
