## 交付了什么

本轮返工任务 R13-T57054072 补齐了 17-测试策略要求的根 `e2e/`、`vitest.e2e.config.ts`、`package.json` 中的 `pnpm -w e2e` 自动化验收体系，并在 `e2e/batch-13-smoke.test.ts` 中完成了对第 13 批真实服务与浏览器全链的主路径及异常边界验收：
1. **浏览器主路径与人工闸门（R1）**：使用正式 daemon bootstrap 启动服务，真实 Chromium 浏览器加载正式 Web 构建产物（`packages/web/dist`）。通过生产路径输入、向导控件完成文档导入、选文档、选批次、逐任务独立指派并写入草稿；将审查闸门配置为手动并点击启动批次派发，真实任务运行并流转至 `awaiting_human` 状态后，在不改变服务端空闲泳道身份的批次树任务行呈现 `GateCard` 审批卡，由 Playwright 真实点击「批准并继续」作出人工审批决定，验证卡片消失、闸门决议为 `pass` 且运行推进至落地。
2. **离线、补推、退避与撤销（R2）**：断网拦截下断言离线横幅包含「最后同步于」、连接状态变为离线且派发能力禁用；记录连续重连请求时间，验证至少 1.5s、3s 且后一次比前一次增长；断网期间 fake-agent 产出的消息在断网期 DOM 呈现严格为 0（负向控制），恢复网络后携带 `Last-Event-ID` 重连成功，断言离线消息在 DOM 中恰好补推一次（`count === 1`，不丢不重）；服务端撤销设备令牌后验证旧流断开、旧凭据请求返回 401、浏览器清除凭据并重定向至 `#/pair` 且停止无限重连。
3. **错误地址、错误页与窄屏（R3）**：手填不可达地址 `127.0.0.1:59998` 时，断言错误提示包含具体网络失败环节及填写的实际地址，且输入框保持可编辑；访问未知 hash 时断言保留 52px 顶栏、显示「未知路径」并可点击「回到运行甲板」导航回 `#/`；访问不存在运行详情时由页面自身兜底渲染「该运行不存在或已被清理」且顶栏在位；在 390×844 窄屏移动端模式下验证 `#/tasks` 批次与任务呈现，并从 `#/run/:id` DOM 提取任务身份和运行状态，与公开 API 严格交叉比对一致。
4. **测试钩子与反造假检查**：生产代码（`packages/web/src`、`packages/daemon/src`）禁绝任何测试钩子（如 `__TEST_HOOK__`、`window.__setToken` 等），严禁对 `spawnManaged` 进行 mock；失败产物与日志目录受 `.gitignore` 保护。
